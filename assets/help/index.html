Reports

What it shows

  • The Start page of the Reports ▾ pulldown: every report of the site under its group, each with its one-line description.
  • Fourteen groups: Overview, Entities, Failures, Server log errors, Use cases & delivery, Activity & volume, Performance, Flow patterns, Protocols & security, Logons & connections, Partners, Configuration, Coverage, Cleanup.

Columns

  • A header row per group, then one row per member: the report (a link to it) and its description. A search hides a group header with no match under it.

Rules

  • The pulldown has one line per group; it opens the group’s first report.
  • On every report page the first row of buttons lists the group’s reports, the current one highlighted; the grey ← Group after the title names the group. Rows below it switch the report’s own tabs or views.
  • Entities keeps the selected view (All, Seen, Error, …) when switching entity.
  • A group mixes transfer-log, server-log and configuration reports that answer the same question.
  • Descriptions are each report’s own DESC; the Report finder and the Site map use the same groups.

Tips

  • The home page (the environment name in the top bar) holds the status tables, the per-day table and the red worklists.
  • Every page reaches its help through the ? in the top bar.
