Reports

What it shows

  • The Reports start page (reached from the Site map): every report of the site under its group, each with its one-line description.
  • Twelve groups: Overview, Entities, Errors (the server log errors included), Use cases & delivery, Activity & volume, Performance, Flow patterns, Protocols & security, Logons & connections, Partners, Configuration, Coverage.

Columns

  • A header row per group, then one row per member: the report (a link to it) and its description. A search hides a group header with no match under it.

Rules

  • There is no Reports pulldown (since 2026-09-30): the top bar links a report of most groups — Overview, Errors, Duration (Performance), Partners, Waiting/Expired, Security, Seen (Coverage), Configuration, Use cases, Patterns, Activity, Entities; Logons & connections is reached from here and the Site map.
  • On every report page the first row of buttons lists the group’s reports, the current one highlighted; the grey ← Group after the title names the group. Rows below it switch the report’s own tabs or views.
  • Entities keeps the selected view (All, Seen, Error, …) when switching entity.
  • A group mixes transfer-log, server-log and configuration reports that answer the same question.
  • Descriptions are each report’s own DESC; the Site map uses the same groups.

Tips

  • The home page (the environment name in the top bar) holds the status tables and the per-day table.
  • Every page reaches its help through the ? in the top bar.
