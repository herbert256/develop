Reports

What it shows

The Reports pulldown in the top bar and its Start page: every report of the site in one of fourteen logical groups — Overview, Entities, Failures, Server log errors, Use cases & delivery, Activity & volume, Performance, Flow patterns, Protocols & security, Logons & connections, Partners, Configuration, Coverage and Cleanup.

Navigation

  • Reports pulldown — one line per group; it opens the group’s first report.
  • First row of buttons — on every report page, the reports of its group; the current one highlighted. Rows below it switch the report’s own tabs or views.
  • Group tag — the grey ← Group after a page title names its group.
  • Start page — every report under its group with a one-line description.
  • Entities — its first row also keeps the selected view (All, Seen, Error, …) when switching entity.

Rules

  • A group mixes transfer-log, server-log and configuration reports when they answer the same question (Overview holds both Top views; Protocols & security holds the SSH security of the server log).
  • Descriptions come from each report’s own DESC line; the Report finder and the Site map list the same groups.
  • The home page (the environment name in the top bar) keeps the status tables, the per-day table and the red worklists.
  • Every report page reaches its help through the ? button in the top bar. Help for reports without data in this environment: Monitor.
