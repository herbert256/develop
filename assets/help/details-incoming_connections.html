Incoming connection details

What it shows

  • One page per whitelisted IP address that carried transfers, opened from the IP cells of the other detail pages’ Incoming connections tables. A whitelisted address without a transfer of its own gets no page; there is no index page.
  • Summary — Metric · Value: IP address, Configured endpoint (when the address is one), Result, Whitelisted by (account count), Files (OK / Error), Volume, First seen, Last seen.
  • Activity per day — Date · Files · Error · OK · Volume.
  • Latest 10 Files — Date · Time · Account · Subscription · File · Size · Outcome. Rows in the File colour.
  • Whitelisted by — every account whose AllowIP whitelist allows this address, each linking its page.

Rules

  • Traffic = every File whose remote host is this address: an incoming connection keeps the raw source IP the partner connected from.
  • Page background = the address’s own result: green when its last File was OK, red when it failed, orange when it expired before pickup (Result: “Warning — last File expired before pickup”) — never the health of its partner’s flows.
  • Error = Failed or Expired; OK = Processed or Waiting.
  • No date filter: every table covers the full period.
