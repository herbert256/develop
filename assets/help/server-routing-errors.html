Advanced Routing errors

What it shows

Advanced Routing errors where a route gives up on a file, one row per server-log line, newest first:

  • Could not send file (AR0074) — the route gave up delivering a file to its transfer site after its retries.
  • Publish to account failed (ARPA0001) — the route could not publish a received file into its account.
  • Post client action error (ARRC0009 and kin) — the action after a received file (typically deleting the source) failed.

Columns

  • Error / Code — which of the three, and the line’s AR code.
  • Account or subscription — the subscription (second bracket), or for a post client action the account (first bracket, before the @); opens its detail page, the row carries its result colour.
  • File — from the braces.

Rules

  • Source: TM lines AR<code>: [<first>] [<second>] <text> carrying “Could not send file:”, “while publishing the file” or “post client action”.
  • Renamed or truncated subscription names resolve to the current configured name.
  • At most 1000 rows and 10 per error and entity, the newest; the total row counts every line in the log.
  • Date filter, search and sort work over the shown rows.

Tips

  • The failure pages call the first two “Duplicate file”, the third “Post client action failed”; a recurring entity has a problem on that step — Errors and its detail page give context.
