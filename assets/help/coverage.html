Entities coverage cells

What this shows

Every number in the Entities and Partners, Domains & Applications pages (the Analyses menu) links to a page like this one, listing exactly the items that cell counts — the configured names (or whitelisted IPs) behind the Configured, Seen and Result figures. The page title repeats the cell (entity group, column, and the count).

The Partners, Domains & Applications page shows its figures in two layouts. In the In & Out table each side is counted whole: an item flowing both ways counts in the In column and the Out column (its list row shows direction In + Out), so In + Out can exceed Total. In the Direction as a partition table the same items are split into In only / Both / Out only, which always sum to Total.

The columns

Name — the configured name; when it appears in the transfer logs it links to its detail page. On the Whitelist pages this is the allowed IP instead, with the account(s) whose AllowIP whitelist carries it. Direction — the entity's configured side: In (the partner connects into SecureTransport) or Out (SecureTransport connects out to the partner); shown on the Configured pages only. On the External Partners page Direction is the pair connection/movement — who dials whom, then which way the file travels — and the Connection, Movement and Use case buttons above the table each narrow the list to one value (the three choices combine; All lifts that group’s filter). That page carries no Last transfer column — the row tint already tells the outcome. Last transfer and Result — the timestamp of the entity's most recent transfer and whether it ended in Error (red) or OK (green); a blank pair on a Configured page means the item was never seen. The Result pages are sorted newest-first on this timestamp, the Configured and Seen pages alphabetically; the External Partners pages sort on the partner name throughout. The Not Seen pages omit Last transfer and Result (always blank there) and carry a Seen column instead. Every row is tinted by the item’s current result (the same status the Entities tables’ Status section counts): light green when its last transfer ended OK, light orange when it was never seen, light red when its last transfer ended in Error.

The External Partners, Internal Applications and Internal Domains pages list each row’s members in two parallel columns, both collapsed to their count (click to expand): Accounts holds the member accounts, Endpoints the matching endpoint per account in the same order — the login the partner connects with (In accounts) or the host SecureTransport delivers to (Out accounts) — so the two opened lists match line by line.

These pages are rebuilt on every publish from the same data as the Show Seen reports, so each list always reconciles with the number on its table.
