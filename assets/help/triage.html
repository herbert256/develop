Triage

What this shows

One worklist instead of six symptom pages: every subscription that needs eyes now — red (last File failed, or server-log evidence after the last OK), expiry-risk (staged Waiting Files 9+ days old; the retention sweep deletes at ~11), or just-went-quiet (last File 8–13 days before the window end).

Rows are ranked by state recency times historical weight — lifetime Files divided by days-in-state+1 — so yesterday's flip on a busy flow outranks a month-old red. Each row carries the symptoms in one line and an evidence pointer onward.

This page is a triage desk, not a diagnosis: From green to red, Went quiet, Waiting, Only red and the Boxes pages remain the deep-dives, linked at the bottom.
