Logical

What it shows

  • One row per logical flow, in the shared Entities layout.

Rules

  • A logical flow is the FlowID family of the configured subscriptions, condensed to one three-part name domain_application_partner; a hyphen inside a part marks parts the derivation combined.
  • input/logical.txt pins a FlowID’s logical name verbatim.
  • A File counts for the logical of its profile’s FlowID and for every logical of its subscription; the Total row, narrowed dates included, counts each File once.
