First seen

What it shows

  • For all nine entity types — Subscriptions, Partners, Logical, Accounts, Logins, Hosts, Domains, Applications, BL — the day each configured name first appeared in the transfer log: one row per log day, newest first.
  • Above the days: Total, Seen, Not seen (opening the matching Entities view).
  • A day cell opens a page of its names — each linking its detail page, with its First transfer timestamp, tinted by its result colour.

Rules

  • Per column: Seen + Not seen = Total.
  • Transfers no subscription claimed (subscription Unknown) are no subscription and are not counted; a Total or Seen cell equals the Entities view it opens.
  • A name seen without a dated transfer of its own (credited through a sibling: a shared endpoint’s co-tenant, one organisation of a two-partner account) counts in Seen but in no day row, so the day rows can sum to less than Seen.
  • Only transfers count: a name the server log mentions but that never transferred is Not seen.
  • Dates: accounts, partners, logical, domains, applications and BL per File; subscriptions, logins and hosts per log record. Names match exactly, case aside; a subscription also matches the logged names it prefixes.

Tips

  • The first log day is naturally the largest row: everything already running is first seen there.
