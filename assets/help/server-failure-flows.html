Failure reasons per flow

What this shows

This report classifies the server log's ERROR messages into failure-reason buckets — the same buckets as the Errors report's Reasons table — and attributes each message to the subscription it names, taken from the connection-failure text, the partner-listing failure text, or the bracketed flow token of an advanced-routing line.

The first table shows, per subscription and reason, how often that failure hit and when it was first and last seen; click a row for its ten most recent error lines. Only messages that name a flow appear there, so its total is a subset of the platform-wide reason totals. The second table counts all classified ERROR records per ISO week, showing how the reason mix moves over time.

Server messages truncate long subscription names: a name that resolves to exactly one configured subscription is shown in full and linked; the rest appear as logged.
