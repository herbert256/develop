Per flow

What it shows

  • The server-log Error lines that name a flow, classified by reason: what breaks for which subscription — the transfer log only says OK or Error.
  • The summary line: errors naming a flow out of all errors, subscriptions, subscription-and-reason pairs.

Columns

  • Subscription — the flow the line names; the row carries its result colour.
  • Reason — the bucket, the same as on Errors › Log reasons.
  • Errors — lines for this pair; Share = its part of all the lines naming a flow.
  • First seen / Last seen — the pair’s first and last line.

Rules

  • The flow comes from a connection-failure line, a partner-listing failure or an advanced-routing line’s bracketed flow token; lines naming no flow are left out, so the total is a subset of Errors’.
  • The server truncates long names: one resolving to exactly one configured subscription shows in full and links its detail page; the rest show as logged.
  • Always the full period; 50 rows per page.

Tips

  • Click a row for its 10 most recent error lines.
  • The Connection failure rows are each flow’s connection failures, the Connection failures box of Subscriptions in boxes.
