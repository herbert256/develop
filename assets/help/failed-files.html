Failed files

What it shows

  • Every File that ended in error (outcome Failed or Expired), one row each, newest first — exactly the Files the home page’s Per day Error cells and the Transfer top view’s Files / Error column count.

Columns

  • Subscription — links its detail page.
  • Date/time — the File’s start.
  • Error reason — the classified fault, as on Open Errors; Expired (not collected) for a staged File the partner never picked up; - when no rule applies. Opens the File’s own page when it has one.
  • CoreId — links SecureTransport File Tracking.
  • Filename — the file’s name.

Rules

  • A File counts on its start day, so a day’s rows equal that day’s home Error cell.
  • Row tint = the subscription’s current colour (see Generic help), not this File’s outcome: a green row failed once and has delivered since. A File with no subscription (Unknown) takes its own colour.
  • 500 rows per page.

Tips

  • A home Error cell opens this page narrowed to its day; a subscription detail page’s Error cell also searches the quoted subscription name (exact match); an Error reasons row searches its reason.
