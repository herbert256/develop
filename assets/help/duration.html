Duration

What it shows

  • How long Files take, per day, in two tables side by side; the summary line gives the File count, median, p95, p99 and max over the window.
  • Two views: Delivered Files (the default) and All Files (every File with a measured duration).

Columns

  • Duration per day — percentiles — Date / Files / p10 / p25 / p50 / p75 / p90 / p95 / p98 / p99 / p100: p95 = 95% of the day’s Files finished at or below it; p100 = the longest.
  • Duration per day — min / avg / median / max — Date / Files / Min / Avg / Median / Max.

Rules

  • A File’s duration is its wall-clock span, first record start to last record end: the store-and-forward gap and retry idle time included, not the sum of the record durations.
  • Delivered Files leaves out the Error Files, whose span is how long they ran before giving up (short attempts or long retry spans); in All Files a failure counts as long as it ran before giving up, so its Max can far exceed the OK view’s.
  • Percentiles use the nearest-rank method. They are not additive: a narrowed date range keeps the day rows but blanks them in the total row; Files re-totals.

Tips

  • A gap between p99 and p100 shows how far the worst case sits from the rest; Longest Files names them.
  • The slowest flows: the Entities Subscriptions page sorted on a Duration column.
