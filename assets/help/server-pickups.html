Pickups

What this shows

Every UC2 flow (the partner connects in and collects files from us) on one row — the detail pages’ Pickup information tables collated, so the whole pickup landscape can be scanned and sorted at once.

The columns

A pickup is a successful SSH logon by the flow’s pickup account in the server log. The logons group into visits (a gap of more than 30 minutes starts a new one); a visit that only delivered files — the account’s UC4 twin flow — is not a pickup. First / Last pickup and Pickups cover the pickup logons; With files counts the pickup visits that collected at least one file of the subscription; Files picked up counts the subscription’s collected Files (its OK figure); Waiting / Expired are its staged files by outcome; Oldest waiting is how long the oldest staged, uncollected file has been waiting, in one unit (“5 days”, “12 hours”, “45 minutes”, “10 seconds”), aged against the newest transfer in the log so an unchanged export does not age between builds — the column sorts by the exact age and the Total row shows the oldest of all; Pattern is the pickup cadence (“Daily”, “Every 15 minutes”, …; “Once” for a single visit, and the spacing between two, when there are too few visits for a median). A 0 renders empty. The visit breakdown and the same-connection (UC4 drop) evidence live on the UC2 pickup visits analysis and each subscription’s detail page.

Last Gateway is the flow’s login’s last logon on the old gateway, joined from the hand-maintained input/<env>/logons_old.txt (one <login> <stamp> per line, the stamp shown as written — the same file the Partners - Incoming page reads) through the subscription’s configured login(s); an em dash means the file does not name the login. The pickup stamps show the date and hh:mm.

The logon columns are the account’s and repeat on each of its UC2 subscriptions; the file columns are each subscription’s own. A partner collecting over CFT/PESIT logs no SSH pickup, so its logon columns stay empty while its files still move.

How it's computed

All figures come from the same per-visit classification that feeds the UC2 status report, the UC2 pickup visits analysis and the detail pages (the uc2-pickups sidecar), so the four views can never disagree.
