Login details

What it shows

  • One page per login, configured or seen in the transfer log, opened from every Login cell. Title prefix = connection/movement direction.
  • Features — the Login first, then each single linked Account, Partner, Domain, Logical, Application or BL; Waiting/Expired (State · Files · First / Last staged) beside it.
  • Activity per day — Date · Files · Error · OK · Volume · Duration (average per delivered File).
  • Logons — Item · Value · Last: First logon, Pattern, Number of logons, then the SSH screening counts Allowed, Disallowed, Authenticated, No account, Bad key, Key failures, Locked, Auth failed, Re-screens, Session errors.
  • Incoming connections (IP · In · Out) — the whitelisted addresses plus those seen; In / Out = Files that entered / left us; an IP opens its incoming connection page. Outgoing connections (adds Name) when the login connects out.
  • Subscriptions — Subscription · Direction · Files · Error · OK · Waiting · Expired (when any) · Volume; a nonzero Error opens Failed files for that subscription.
  • Last error(s) — Date & time · Subscription · File: per subscription with a failed File, its newest one; the whole row opens that File’s page.
  • Accounts, Logical, Applications, BL — when there are several.
  • Load by weekday / hour (Files · Error · OK · Volume); Dwell (Files per store-and-forward wait, with Share).
  • Duration per leg (min, avg, max, p50, p95, p99 of the OK legs), Size (Volume, Throughput, Average, Largest), Date (First / Last seen, Busiest day, Active days), Ranking (position among all logins; each row opens Ranking).
  • Last server log messages (its 25 newest lines) and Last server log errors (its newest 10 Error and 10 Warning lines, plus those of its 1-to-1 connected entities after its last transfer).

Rules

  • Page background = the login’s result colour: red when any connected subscription is red, green when all are green, else orange (see Generic help).
  • A logon = a successful authentication in the server log, any protocol; Pattern = the typical spacing of its visits (a gap over 30 minutes starts a new one).
  • Logons rows with a zero count are left out; failure rows are red. Re-screens = an Allowed on an already authenticated connection (a re-key), not an attempt. Same figures as the Logons Incoming tab.
  • Counts are Files (Error = Failed or Expired). Subscriptions and breakdown rows take the linked entity’s result colour.
  • Connection rows: green configured with traffic, red traffic on an unconfigured address, orange configured without traffic (folded behind one orange row).
  • An Error line newer than the end of its last transfer raises the red ERRORS IN SERVER LOG AFTER LAST TRANSFER banner.
  • No date filter: full period. A never-seen page keeps Features, Logons, Subscriptions and the connection tables.
