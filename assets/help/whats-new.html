What is new

What it shows

Two tables from the git history of the report scripts: the 10 most recently added reports and the 10 most recently changed ones, each linking its page with a one-line description.

Rules

  • A change counts only when a commit was about one report (it modified exactly one generator).
  • A report in the New table is not repeated in Changed — added and changed on the same day is one piece of news.
  • Unpublished intermediates (the merged reports’ components) never appear; the tables are empty when git is unavailable.
  • Reached from the Site map’s Tools card only.
