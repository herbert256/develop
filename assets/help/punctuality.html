Punctuality

What it shows

  • Does each subscription’s file arrive on time? The Arrival time tab models the time of day; the Rhythm tab the gaps between active days (its own help).

Columns

  • One row per subscription active on 8+ days, tightest flows first.
  • Active days — days with at least one File.
  • Typical arrival — the median arrival time; a day’s first File is that day’s arrival.
  • Window / Class — the spread (one standard deviation): Clockwork ±15 min, Regular ±1 h, Loose ±3 h, Irregular wider (event-driven).
  • Late — arrivals over an hour past the typical arrival.
  • Missed days — a weekday the flow serves on 75%+ of its occurrences that passed without any File.
  • Last seen — the newest active day.

Rules

  • Late and Missed days count for Clockwork and Regular flows only; the others show “-”.
  • Missed days are counted from the flow’s first day; the window’s last day counts only when the data reaches past the typical arrival plus an hour.
  • Always the full period: the model needs the whole window.

Tips

  • Click a row with Late or Missed counts for the exact dates.
  • Polling shows the configured schedules these arrivals should match.
