Configured subscriptions

What it shows

  • Every configured subscription on one row, the skip-listed ones included, ordered by use case, then name. The title carries the time of the FlowManager export (FM export).

Columns

  • Subscription — links its detail page. Use case — the UC<n> prefix, else the use case derived from the configuration.
  • Active — Yes, or why not (hover for the words): 1 Undeployed, 2 SAVED_NOT_DEPLOYED, 3 receive schedule No, 4 folder monitoring Inactive. A SWIFT name shows CFT.
  • Color — the result as a word: green, red, orange; white = none (a skipped subscription).
  • Direction — connection/movement, as in the detail page title: out/in = ST connects out, the file comes in; both = a relay; ? = unknown.
  • Endpoint — inbound the partner’s login, outbound the remote host. From / To — source and target folders, the pickup side’s file mask in green; - = none.
  • Total files, In Files, Out Files, Errors (Failed or Expired), Automatic, Resubmit OK / Resubmit Error, Waiting, Expired — Files over the whole data set.
  • Error reason — the newest File in error, as on Failed files; links its error page.
  • Logical, Account, Partner, Domain, Application, BL — the groups, each linking its detail page.
  • Cron expression / Schedule — the receive scheduler and its plain-English reading, as on Polling.

Rules

  • A subscription skip.txt skips shows n/a counts, no groups and no tint.
  • A zero shows blank; a subscription never in the transfer log has blank counts.
  • Row tint = the result colour (see Generic help). Every load opens in the generated order.
