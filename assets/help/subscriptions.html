Subscriptions (analyses)

What it shows

Every configured subscription on one row: its groups, its endpoint and folders, and its all-time File counts. Ordered by use case, then name.

Columns

  • Subscription — the complete configured name; links the detail page.
  • Logical, Account, Partner, Domain, Application, BL — the owning account and the derived groups (BL = the tags entry starting with BL); each links its detail page.
  • Endpoint — inbound: the login the partner connects with; outbound: the remote host we dial.
  • From / To — the source and target folders exactly as the detail page’s Features rows: the pickup side carries its file mask in green; - = nothing configured.
  • Cron expression / Schedule — the configured receive scheduler (Quartz sec min hour day-of-month month day-of-week) and its plain-English reading, exactly as on the Polling page; blank without one.
  • Total files, In Files, Out Files — the Files (one per CoreId) this subscription carried over the whole data set, by movement direction.
  • Errors — Files that ended Failed or Expired (red).
  • Auto Retries — OK Files with a failed leg and no resubmit: the platform retried (amber).
  • Resubmit OK / Resubmit Error — the Files an operator resubmitted, by final outcome.
  • Waiting / Expired — UC2 Files staged but not collected yet, and the ones deleted unclaimed.

Rules

  • Roster = the pristine configured snapshot: exactly what FlowManager defines. Groups, endpoint, folders and cron come from the configuration; the counts from the log, the Entities definitions, all dates. A subscription never seen in the log shows blank counts; a 0 shows blank.
  • Row tint: light green last transfer OK, light orange configured but never seen, light red a last transfer in Error, light blue surfaced only by the server log.
  • Every load starts at the generated order; click a header to sort.
