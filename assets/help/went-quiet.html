Went quiet

What it shows

  • The silence report: subscriptions that carried Files and then stopped. Nothing fails when a flow stops, so no other report shows it.

Columns

  • Boxes Subscriptions with Files and Went quiet; per quiet subscription (links its detail page) Days ago last traffic, longest-quiet first.

Rules

  • Rows tint by the subscription’s result colour.
  • A subscription is quiet when its newest File is more than 7 days before the last day in the data. Every outcome counts as traffic: the question is “is anything happening”, not “is it working”.
  • A subscription that never carried a File cannot go quiet; the Entities Not seen view lists those.
  • Measured from the window end, never today; always the full period.

Tips

  • Health is judged on Open Errors.
