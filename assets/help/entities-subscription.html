Subscriptions

What it shows

One row per subscription. Internally the entity is the “Transfer Site” (report basename transfer-site, cache column, detail-page folder); every label the browser shows reads Subscription. Columns, rules, views, scope and drills are the same on all nine entity pages: see Entities.

How a File is attributed

  • A subscription is a per-row attribute (a transfer has a source and a destination subscription): distinct (subscription, CoreId) pairs are counted, so a File on two subscriptions counts for both and the per-subscription counts can sum to more than the distinct total.
  • The Files group’s Error count opens Failed files for that subscription and the selected From/To dates (the other count cells still open their 10 most recent Files).
  • Only logged transfer activity counts here; whether a configured subscription has been seen at all is the Coverage question.
  • The Error view adds a Reason column, the per-flow diagnosis of the front page’s two red tables: the verdict of the flow’s newest failed File (its error page) unless the flow is red for server-log reasons; else the classified newest server Error line; else the most specific box of the Boxes page.
