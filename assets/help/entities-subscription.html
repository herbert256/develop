Subscriptions

What it shows

  • One row per subscription, in the shared Entities layout.

Columns

  • Reason — Error view only: why the flow is red, the same Reason as Failed Subscriptions. It links the evidence: the failed File’s error page, the flow’s server-log error page, or its detail page.

Rules

  • A subscription is named per leg: a File whose legs name two subscriptions counts for both, so the rows can add up to more than the Files.
  • The Files group’s Error count opens Failed files for that subscription and the selected dates instead of a drill-down.

Tips

  • Which configured subscriptions were seen at all: Entity coverage.
