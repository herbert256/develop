Blast radius

What it shows

  • What stops when a remote host dies. Boxes: outbound endpoints, partners seen, and the partners with a single endpoint, multiple endpoints or none (inbound-only), plus the shared endpoints.
  • If this host dies — one row per outbound endpoint, busiest first: Host, Files, Volume, distinct Subscriptions, Applications, Domains and Partners, their names in Partner(s), and Sole endpoint for — the partners with no other endpoint.
  • Shared endpoints — hosts serving several partners: Host, Partners, Partner(s), Files.

Rules

  • Endpoints come from OUT-connection Files only: an inbound File records the partner’s source address, not an endpoint we dial.
  • A red row is the sole endpoint of at least one partner — nothing to fail over to.
  • Inbound-only partners dial us, so no endpoint of theirs can strand us: a legitimate class, not a gap.
  • Applications and partners use the union rule: a File counts for its own and every configured one of its subscription.
