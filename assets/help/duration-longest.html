Longest Files

What it shows

  • The 250 longest delivered Files by wall-clock duration — first record start to last record end, so the store-and-forward wait inside SecureTransport and any retry idle are included — at most 10 per subscription, so one slow flow cannot fill the list.

Columns

  • Duration — the span; sorts by the exact milliseconds.
  • Start Time / End Time — the first record start and the latest record end.
  • File — the file name.
  • Destination Subscription — linked to its detail page.
  • CoreId — the File’s id.

Rules

  • Only Processed (OK) Files: a Failed, Expired or Waiting File is not a completed transfer, and a failure’s run time is a timeout, not a duration.

Tips

  • Every listed File has a File page — a click anywhere on the row opens it (the subscription cell opens its detail page): its facts, every record of the CoreId and the server log of its connections. Rows green, or orange after a retry or resubmit (the File colour).
