Longest Files

What it shows

  • The 50 longest delivered Files by wall-clock duration — first record start to last record end, so the store-and-forward wait inside SecureTransport and any retry idle are included.

Columns

  • Duration — the span; sorts by the exact milliseconds.
  • Start Time / End Time — the first record start and the latest record end.
  • CoreId — the File’s id.
  • Destination Subscription — linked to its detail page.
  • File — the file name.

Rules

  • Only Processed (OK) Files: a Failed, Expired or Waiting File is not a completed transfer, and a failure’s run time is a timeout, not a duration.

Tips

  • The Duration, Start Time, End Time and CoreId cells open a File page when the File has one (per subscription the newest OK File and the three newest Error Files): its facts, every record of the CoreId and the server log of its connections. Rows green, or orange after a retry or resubmit (the File colour).
