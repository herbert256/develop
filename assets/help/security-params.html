Security Parameters

What it shows

  • Every attribute parsed from the transfer log’s free-text SecurityParameters column, in one table. A summary line gives all transfers with their Error / OK split.

Columns

  • Attribute — TLS version, Cipher, Cipher suite, MAC, Key Exchange, Public Key.
  • Value — each attribute’s values, busiest first; a value opens its own page.
  • Transfers — the OK legs that used it.

Rules

  • Counts transfers (legs), not Files: parameters are negotiated per leg, so one File’s Inbound and Outbound legs can differ.
  • A leg counts once per attribute, so Transfers does not add across attributes: the Total stays blank.
  • “TLS version” is the log’s Protocol: key, renamed to keep it apart from the transfer protocol (see Protocol, Direction & Mode).
  • Value pages — every Subscription that used the value, with its Partner and Transfers, then a Partners table (Partner, Subscriptions, Transfers). Full period. A leg counts under every partner of its subscription and under its remote host’s partner.

Tips

  • Deprecated values and who still uses them: Security outreach.
