Transfer Security Parameters

What this shows

Connection security for transfers: one view per attribute found in the log's free-text SecurityParameters column — TLS version (labelled so rather than "Protocol" to avoid confusion with the transfer protocol), Cipher, Cipher suite, MAC, Key Exchange and Public Key. The buttons under the title switch between the attributes; one table shows at a time. An attribute the environment's traffic never negotiates shows an empty table. For the transfer protocol distribution itself, see the Protocol report in the same group.

How it's computed

SecurityParameters is negotiated per connection leg, so every table here counts individual transfers (legs), not Files — the Inbound and Outbound rows of one File can use different ciphers or protocol versions. Each attribute value's row shows the transfer count and its Error/OK split.

Click an Error or OK count to expand that outcome's 10 most recent transfers.

Click a value in the first column of any table (a cipher, MAC, key exchange, public key, cipher suite or TLS version) to open a page listing every subscription that used that value — with its partner and transfer counts, each subscription and partner linking to its own detail page — followed by a Partners summary table rolling those subscriptions up per partner. Those per-value pages are full-period (not date-filtered).
