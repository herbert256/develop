Security Parameters

What it shows

  • The cryptography in use, from both logs, on one page: first the transfer log’s SecurityParameters column per leg, then the server log’s SSH tables (SSH security until 2026-09-30).

Columns

  • Attribute (TLS version, Cipher, Cipher suite, MAC, Key Exchange, Public Key), Value (busiest first; opens its page: the Subscriptions and Partners that used it), OK transfers (OK legs; Unknown-subscription legs left out, the summary line keeps them).
  • Negotiations by protocol, Cipher suites, Key exchange, MAC algorithms, Public-key algorithms — Negotiations, Share, Assessment (OK or red Weak), First, Last.
  • Deprecated-parameter warnings — Parameter, Account, Subscription, Remote host, Warnings; rows tint by the subscription’s colour.
  • Algorithm negotiation failures, PeSIT TLS adoption (the ST–CFT link over TLS, with Per week), Session-lifecycle problems; Hygiene signals and Certificate chain errors only when logged.

Rules

  • A value page (click a Value): the Subscriptions table tints by the subscription’s result colour, the Partners table by the partner’s; “Security Parameters” above the table leads back.
  • The first table counts legs, once per attribute, so its Total stays blank. “TLS version” is the log’s Protocol: key.
  • Weak: CBC / 3DES / RC4 ciphers, SHA-1 key exchange or MAC, ssh-rsa / ssh-dss keys.
  • The SSH tables re-total under the date filter; a row opens its 10 most recent log lines.
  • Deprecated values and who still uses them: Security outreach.
