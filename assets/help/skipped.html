Skipped

What it shows

  • What the skip list removed at parse time — accounts, subscriptions, logins and the log lines set aside with them — plus the raw transfer records dropped for other reasons. No other report, detail page or search counts them.
  • Six boxes: skipped accounts, subscriptions, logins, transfer log lines, server log lines and no-subscription / http / probe lines.

Columns

  • Skip rules — Rule, then what it caught: Accounts, Subscriptions, Logins, Transfer log lines, Server log lines.
  • Skipped accounts / subscriptions / logins — the name and the Rule that caught it.
  • No subscription / http / empty probe — the dropped raw records: Date & time, Reason, Status, Account, Login, Direction, Protocol, File, Size, CoreId.

Rules

  • The rules are input/skip.txt, one token per line, this checkout’s own; edit it and rebuild.
  • Configuration names match on a case-insensitive substring (CRG matches IPO_CRG-OK01_RABOBANK); log records follow the rule kind (contains, exact or regex). A skipped login loses its detail page; to hide it from the server log too, use an any rule.
  • Reasons: http = the CoreId has an http leg (web-UI traffic); empty ssh probe = one lone outbound ssh record of size 0, Application none; otherwise no subscription = no leg carried a subscription or account.
  • A record with an account but no subscription is kept, with subscription Unknown: a routing gap to investigate, listed on Unknown transfers.
