Entities

What it shows

  • The layout of the nine entity reports: one row per name, six column groups; each entity’s help gives its attribution.
  • Views: All = every configured and logged name; Seen = the names in the transfer log; Not seen = configured, never logged (name only); OK / Warning / Error = result green / orange / red.

Columns

  • Files — In / Out by movement (else connection side), Error, Error %.
  • Retry — Auto = OK Files with a failed leg, none resubmitted.
  • Resubmit — Ok / Error = resubmitted Files by final outcome.
  • Duration — p90 … p100 span of the delivered Files, nearest rank; seconds green, minutes amber, hours and days red.
  • Volume — Total, Avg per File.
  • Transfers — their legs: Ok, Error, Error %.

Rules

  • Waiting counts as OK, Expired as Error. Figures follow From/To. Retry and Resubmit each show only while a visible row has a value. Waiting and Expired Files per subscription: Waiting & Expired.
  • Logical, Partners, Applications and BL can count a File for several names; their Total counts it once. OK / Warning / Error views sum their rows.
  • Row tint = the name’s result (Generic help); untinted = not configured.

Tips

  • A count opens its 10 newest Files; a Transfers cell those with such a leg; a Duration cell those at or above it.
