Entities

What it shows

  • The shared layout of the nine entity reports: one row per name in seven column groups; each entity’s help says how a File is attributed.
  • Views: All = every configured and logged name; Seen = the names in the transfer log; Not seen = configured, never logged (name only); OK / Warning / Error = result green / orange / red.

Columns

  • Files — In / Out by movement direction (none known: the connection side, so In + Out = Files), Error, Error %.
  • Retry / Resubmit — Auto = OK Files with a failed leg, none resubmitted; Ok / Error = resubmitted Files by final outcome.
  • Duration — p90 / p95 / p99 / p100 wall-clock span of the delivered (Processed) Files only, nearest rank; seconds green, minutes amber, hours and days red.
  • Volume — Total, Avg per File.
  • Transfers — the legs of those Files: Ok, Error, Error %.
  • State — Waiting (UC2, uncollected) and Expired (deleted unclaimed) Files.
  • Dates — First, Last, Days with traffic.

Rules

  • Waiting counts as OK, Expired as Error. Figures follow From/To, except First and Last. Retry / Resubmit and State show only while a visible row has a value.
  • Logical, Partners, Applications and BL can count a File for several names; their Total row counts it once, also under a narrowed date range while no search hides rows. OK / Warning / Error views sum their rows.
  • Row tint = the name’s result: green last File OK; red last File Failed, or server-log errors after it; orange never logged, or last File Expired; untinted not configured. Other entities roll up their subscriptions (Generic help).

Tips

  • A count opens its 10 newest Files; a Transfers cell the Files with a leg of that outcome; a Duration cell the delivered Files at or above that percentile.
  • Your sort, every key of a multi-key sort, carries across the nine entities for an hour. Every view, Error included, has the cols picker.
