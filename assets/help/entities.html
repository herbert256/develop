Entities

What it shows

  • The layout of the nine entity reports: one row per name, seven column groups; each entity’s help gives its attribution.
  • Views: All = every configured and logged name; Seen = the names in the transfer log; Not seen = configured, never logged (name only); OK / Warning / Error = result green / orange / red.

Columns

  • Files — In / Out by movement (else connection side), Error, Error %.
  • Retry / Resubmit — Auto = OK Files with a failed leg, none resubmitted; Ok / Error = resubmitted Files by final outcome.
  • Duration — p90 … p100 span of the delivered Files, nearest rank; seconds green, minutes amber, hours and days red.
  • Volume — Total, Avg per File.
  • Transfers — their legs: Ok, Error, Error %.
  • State — Waiting (UC2, uncollected) and Expired (deleted unclaimed) Files.
  • Dates — First, Last, Days with traffic.

Rules

  • Waiting counts as OK, Expired as Error. Figures follow From/To, except First and Last. Retry / Resubmit and State show only while a visible row has a value.
  • Logical, Partners, Applications and BL can count a File for several names; their Total counts it once (while no search hides rows). OK / Warning / Error views sum their rows.
  • Row tint = the name’s result (Generic help); untinted = not configured.

Tips

  • A count opens its 10 newest Files; a Transfers cell those with a leg of that outcome; a Duration cell those at or above it.
  • Your sort carries across the nine entities for an hour.
