Accounts

What this shows

One row per account name: how many Files it drove, how many failed vs. processed, how much volume it moved, and the first/last day it was seen. A Summary tab lists every account; a Detail tab breaks the same figures down per account per day — see the shared concepts page for what a File is.

How it's computed

The report reads the per-CoreId cache (_files.tsv) directly: one logical transfer per File, split Error/OK by its delivered (final-row) outcome, volume counted once per file. The account name is the one recorded on the File's first row — so if a transfer's first leg ran under a shared service account before its real owner took over on a later leg, the File still gets attributed to the real account, not the service account.

Both tabs support click-to-expand on an Error/OK cell for that outcome's 10 most recent Files.

The tab row: views and scope

The tab row carries three groups: the entity type (Subscriptions, Logical, Partners, Accounts, Logins, Hosts, Domains, Applications, BL), then the view, then the scope. Switching one keeps the other two, so you can walk from entity to entity without losing the view you were reading.

The six views are All (every configured name plus every logged one), Seen (the names with activity), Not seen (configured in FlowManager, never seen — name column only), and OK / Warning / Error, the names whose result is green / orange / red.

The scope decides whether a sighting in the server log counts as being seen. +Server is the default and counts it: an entity that only ever turned up in server-log messages — never in a transfer — is listed under Seen and shown light blue. Transfer ignores the server log, so that same entity counts as never seen: it drops out of Seen and turns up under Not seen and Warning instead, in the ordinary never-seen light orange. The scope only changes three of the views — Seen, Not seen and Warning. All lists the same names either way, and only a real transfer ever makes a name green or red, so OK and Error are the same list too: on those three views the scope tabs are greyed out. Under +Server the view row also offers a seventh view, Server — the names seen in the server log and nowhere else, i.e. exactly what that scope adds to Seen. It is not offered in the Transfer scope, where those names are simply never seen. This is the same choice as the including server log switch on the front page, and the front-page figures link straight into the matching view and scope.
