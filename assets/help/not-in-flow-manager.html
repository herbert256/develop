Not in Flow Manager

What it shows

  • Every entity value in the transfer log that the current FlowManager configuration does not know — traffic running outside the configuration. The summary line gives the unconfigured values, the Files they touched and their volume.

Columns

  • Type — Account, Subscription, Login, Host, Whitelist, Logical, Partner, Application, Domain or BL; rows grouped per type.
  • Name — the logged value; links its detail page where one exists.
  • Files, Error, OK (by each File’s outcome), Volume (each file once).
  • First seen / Last seen — the start of the oldest and newest File carrying the value.

Rules

  • Case-insensitive comparison with the configured lists; a logged subscription counts as configured when a configured name prefixes it (logged values carry protocol suffixes).
  • Host = an outbound endpoint we dialed that partners.json does not list; Whitelist = an incoming source address no AllowIP entry covers.
  • The configuration is compared as it is now: a since-deleted object and a never-configured one look the same. A missing FlowManager export lists every logged value of that type.

Tips

  • Typical hits: ad-hoc test uploads, objects renamed or deleted after the log was written, partner addresses missing from the whitelist.
