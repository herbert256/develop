Errors per Day

What this shows

This report is built from the server log (data/<env>/server/cache/_parse.tsv), the platform's own info/warning/error messages — not the transfer log. Every number here is a plain count of log records, not Files. Two tables: records per day split by level (Info/Warning/Error, with the error rate), and the same split per component (TM, PESITD, SSHD).

The report is tabbed: this page covers Errors per day; its sibling tabs have their own pages — Error reasons groups the same errors by what the message says.

How it's computed

One pass over the parse cache counts every record by date and by level, and separately by component and level. The per-component table carries per-day buckets so it re-aggregates correctly under the date filter. Levels other than Info/Warning/Error (none expected in practice) are counted in Records only, not broken out.
