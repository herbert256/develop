Day page

What it shows

  • One data day of both logs, opened from a Date cell of the home page or a dashboard slot; the arrows beside the title step a day.
  • KPI cards — Files, File error rate, Volume, Server lines, Server error rate, each with its change against the same weekday’s average.
  • Graph — Duration, OK Files, Volume, Error % Files, Transfer errors, PeSIT, EventQueue, in 15-minute, 30-minute or 1-hour slots (see Dashboard): Duration = delivered Files, nearest rank; Transfer errors = every non-Processed leg.
  • Server log problems this day / Transfer log problems this day — one line per signal with its count, linking its report.
  • Remarkable facts — only what stands out: a dominating account, the longest transfer, the largest file, weekend activity…
  • Busiest this day — the top 5 partners and subscriptions by Files, Volume and Errors.

Rules

  • Transfer figures count Files, server figures log lines; both match the day’s Top view rows.
  • No From/To: the page is the day. KPI, graph and problem links open their report narrowed to the day where it can follow a date.
  • Problem lines appear only when they apply. Server log: Server errors/warnings, Logon screening failures, Outbound logon failures, Connection failures, Route stopped, Event-feed errors, No remote dir, No remote files, Trouble after success.
  • Transfer log: Files in error, One-legged Files, Went red, Never delivered, Waiting for pickup, Expired before pickup, Anomaly scan.
  • Partner figures count a File for every partner of its subscription; See more opens the Entities view narrowed to the day.
  • The graph view and style follow you across days and from the dashboard.
