Sizes & types

What it shows

  • The files themselves: sizes, types, repeated names and the largest Files.

Tabs

  • By size — Files / Error / OK / Volume / % of Files / Distribution in nine buckets, 0 B to >= 1 GB.
  • Empty files — per subscription, the zero-byte Files delivered OK, First / Last.
  • By type — per extension: Transfers / Error / OK / Volume / % of transfers; counts legs.
  • Duplicates — names transferred more than once, any outcome: Files / Error / Accounts (distinct senders) / First / Last; full period.
  • Largest files — the 50 largest Files: Size / Throughput (size ÷ wall-clock span) / Start / Account / Subscription / Outcome / File, in the File colour.

Rules

  • Empty files delivered OK: rows tint by the subscription’s result colour. A size bucket without Files shows empty cells.
  • All tabs but By type count Files; Error = Failed or Expired.
  • The 0 B bucket holds every empty File, failed or not; only the OK ones reach Empty files.

Tips

  • Duplicates with Error below Files usually mean a failed transfer was re-sent successfully.
