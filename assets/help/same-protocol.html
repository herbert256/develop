Inbound and Outbound same Protocol

What it shows

  • The Files whose first inbound leg used the same protocol as their last outbound leg — for example an SFTP upload that also left over SFTP instead of going on to the CFT. The summary line under the tables counts them.

Columns

  • Per subscription (first table) — Subscription, Protocol, Files, OK, Error, First and Last day. Full period: From/To does not narrow it.
  • Files — every File, newest first, 500 per page: Subscription, Date/time (the File’s start; From/To reads it), Protocol, First inbound and Last outbound (their leg start times), Legs, Outcome (OK green, Error or Expired red, Waiting plain), CoreId, Filename.

Rules

  • Per File: the protocol of the inbound leg with the earliest start is compared with that of the outbound leg with the latest start; listed when both exist and are equal.
  • Protocols as logged: ssh (SFTP), ftp, pesit, routing.
  • Rows tint by the subscription’s result colour (see Generic help).
