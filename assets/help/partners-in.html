Partners - Incoming

What it shows

  • One row per FE login (the credential a partner connects with): its use cases, last logons, Files and pickups, beside its SSH screening counts from Logons › Incoming. Full period; no date filter.

Columns

  • Login — links its detail page. Use cases — UC2 (the partner picks up), UC4 (the partner delivers) or UC2/UC4.
  • Cloud — the newest successful logon on this platform, any protocol. Gateway — the last logon on the old gateway, from input/logons_old.txt.
  • Files in / Files out — Files delivered to us / picked up from us, by movement.
  • Error — Files that failed; Retrieved / Waiting / Expired — staged Files collected / not yet collected / deleted by retention before pickup.
  • Oldest waiting — the oldest uncollected File’s age, against the newest transfer in the log.
  • Pickups — pickup logons, counted once per login and account.
  • Allowed / Disallowed / Authenticated / Locked — the screening funnel; Auth Failed = Bad key + Key failures + Auth failed in one count.
  • Pattern — the logon cadence.

Rules

  • Rows: every configured FE login, every login only the old-gateway file names, then logins only the funnel knows (empty transfer cells, untinted).
  • Row tint = the login’s result colour (see Generic help); the funnel’s red cells keep their red. A 0 renders empty.
  • input/logons_old.txt: one login and its stamp per line (FE000123  2026-09-02 14:35); blank and # lines ignored.

Tips

  • Click a funnel count for its 5 newest log lines.
