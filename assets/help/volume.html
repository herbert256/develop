Volume

What it shows

  • The bytes each entity moved: one tab per entity type, in the Entities order — Subscriptions, Logical, Partners, Accounts, Logins, Hosts, Domains, Applications, BL.

Columns

  • Total — the bytes of the entity’s Files, in whole units. Avg — Total ÷ Files.

Rules

  • The same Files and attribution as the Entities pages; most bytes first. Figures follow From/To.
  • Logical, Partners, Applications and BL can count a File for several names; their Total counts it once.
  • Row tint = the name’s result; untinted = not configured.
