Domain Details

What this shows

This is the per-domain detail page. A business domain is the FIRST part of the three-part logical flow name (domain-application-partner), so the identity is name-derived — the same grouping as the Domains row on the Logical, Partners, Domains & Applications page. The page opens with a one-line KPI summary, then Activity per day / week / hour / weekday, a breakdown of every dimension the domain's transfers touch (account, subscription, login, remote host, protocol, AV scan, security parameters, direction, action-by, mode), and the 10 largest transfers.

The entity tables are cross-referenced against the FlowManager configuration: every name configured for this domain is listed, whether it appears in the logs or not — green rows have logged data, red rows are configured but never seen, each linking to its own detail page.

Last error(s)

Directly above the Features table, a page carries a Last error(s) table whenever any subscription it moves files with has something wrong on it: one row per such subscription — its most recent error, newest first — with the date and time, the subscription and the file. Rows are tinted by kind, red for a failed file and orange for one that expired before the partner collected it, and there is no table at all when nothing connected to this entity has an error.

Clicking anywhere on a row — the subscription name included — opens that file’s error page, with every transfer leg and the server log of the failure. Those are the same files the Failed Subscriptions list holds: that page guarantees every subscription’s last error has a page, which is what lets this table link straight to it.

Direction, page colors and never-seen pages

Every configured domain has a page — seen in the logs or not —. The page background color says the same at a glance: light brown = seen & in, light blue = seen & out, light gray = seen & both/unknown, light yellow = never seen & in, light orange = never seen & out, light purple = never seen & both/unknown.

A domain configured both ways splits every outcome into four columns — In - Error / In - OK / Out - Error / Out - OK — by each file's own direction; a file with no direction of its own counts in Files and Volume only.

When a page carries both green (logged) and red (configured-only) rows, the tint tells them apart at a glance. The Activity per day table leads with the Files count; the Subscription breakdown comes first below it, and the Account breakdown renders right under the Incoming/Outgoing connections tables.

How it's computed

The KPI line reports this domain's rank and share of traffic among all domains, its failure rate, total volume and cadence, plus processed-transfer performance and a session count where durations are recorded. Every count is in Files: one per logical transfer, split by its delivered (final-row) outcome, volume counted once per file.

A Partner, Application, Domain or Logical breakdown holding exactly one row is folded away: the name appears as a row in the Features table instead, keeping its link and colour.
