File in - File out › UC4 to UC2

What it shows

  • Files a partner delivered on a UC4 subscription and then collected back through the matching UC2 subscription: the file did not move on to the CFT quickly enough, so the partner’s own pickup took it.

Columns

  • Per subscription pair — UC4 subscription, UC2 subscription, Login, Files, the delivery-to-collect gap (Fastest / Median / Slowest), First and Last collect. Full period: From/To does not narrow it.
  • Files — every pair, newest collect first, 500 per page: File, Login, UC4 subscription, UC4 date/time, UC2 subscription, UC2 date/time, Gap, UC4 CoreId, UC2 CoreId. From/To narrows it by the UC4 date/time.

Rules

  • A pair needs the same file name, the same login, the same subscription name apart from the UC4 / UC2 prefix (case ignored), and the UC4 File starting earlier.
  • Each UC2 File pairs with the newest such UC4 File. The use case comes from the name prefix only.
