Sources and Targets

What it shows

  • The From / To folder paths configured on every subscription, and where they overlap. One row = one subscription using one path; rows of one path are grouped.

Columns

  • Values used as both a Source and a Target — Value, Role (Source or Target for that subscription), Subscription, Error, OK: a path one subscription writes and another reads — an internal hand-off.
  • Sources used by multiple subscriptions — Source, Subscription, Error, OK.
  • Targets used by multiple subscriptions — Target, Subscription, Error, OK.

Rules

  • Source and target are the From and To rows of the subscription detail page’s Features table.
  • A remote-partner endpoint (one SecureTransport dials) shows its host after @ (/some/dir @ sftp.example), as on the Search page; a local path has none. The host goes on the remote side: the source on a pull flow, the target otherwise.
  • Error / OK = the subscription’s own Files by outcome, full period (no date filter).
  • Rows tint by the subscription’s result colour (see Generic help).
