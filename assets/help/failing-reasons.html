Error reasons

What it shows

One row per error Reason: how many Files in error carry it (Count) and the newest occurrence (Last) — the failure profile of the whole data at a glance.

Rules

  • Count = every File in error, Failed or Expired, recovered flows included: the rows of Failed files, so the Total equals that list and the home page’s Error total.
  • The reasons are the Failed files page’s: the shared classifier vocabulary (Connection failures, PeSIT transfer aborted, …) in classifier order, One-legged, the raw last-leg status and Expired (not collected); (none) when no rule applies.
  • Only reasons that occur are listed: a reason with nothing counted has no row.
  • Sorted by Last, newest first; the Total row sits at the bottom.

Reason pages

  • A row opens every File with that reason, newest first, 500 per page: Subscription (links its detail page), Date/time (the File’s start), CoreId (links File Tracking where configured) and Filename. A click elsewhere on the row opens the File’s error page when it has one.
  • Rows tint by the subscription’s result: light green last transfer OK, light orange configured but never seen, light red last transfer in Error, light blue surfaced only by the server log.
  • From/To narrows the rows to a date range; the search box filters them.
