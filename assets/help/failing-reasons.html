Error reasons

What it shows

  • The failure profile of the whole data: one row per error reason that occurs, with the Files in error carrying it.

Columns

  • Reason — the Error reason of Failed files: the classifier’s vocabulary (Connection failures, PeSIT transfer aborted, …), One-legged, a raw last-leg status, Expired (not collected); (none) when no rule applies.
  • Count — the Files in error (Failed or Expired) with this reason, recovered flows included.
  • Last — the newest such File’s start; the default sort, newest first.

Rules

  • The Total equals the Failed files list and the home page’s Error total; a busy flow counts as often as it failed.
  • A reason with nothing counted has no row. Always the full period.

Tips

  • A row opens Failed files searched on that reason ((none): the whole list).
  • This page counts Files; the Errors report’s Log reasons tab counts server-log lines in its own vocabulary.
