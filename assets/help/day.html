Activity

What it shows

  • Transfer activity at three resolutions, one tab each: per ISO week, per hour of day (plus the hour × weekday grid) and per weekday. The per-day figures are the Transfer top view.

Tabs

  • Per week — Week / From / To / Days / OK Files / Avg/day / Error % / Volume / Δ OK Files. One row per ISO week (Monday–Sunday) by start date; Days = days with data.
  • Per hour — Hour / OK Files / Volume / Load: OK Files = the OK Files started in that hour, Volume = their bytes, Load = a bar against the busiest hour.
  • Hour × weekday — Hour, then Monday…Sunday: the OK Files starting in that hour on that weekday, tinted by quartile of the busiest cell, so batch windows show as dark blocks.
  • Per weekday — Weekday / Days / OK Files / Avg/day / Error % / Volume / Load; Days = how often that weekday was observed.

Rules

  • OK Files = Processed + Waiting, Volume = their bytes; Error % = the failures over every File of the week or weekday; Avg/day divides OK Files by Days.
  • Δ OK Files = the change of OK Files against the previous week, in %; the first week shows “-”.
  • (partial) after a week marks one observed on fewer than 7 days — the edges of the data window — so its Δ is not meaningful.
  • The date filter re-sums the hour and weekday tabs (the grid re-tinted) and hides the weeks outside the range.
