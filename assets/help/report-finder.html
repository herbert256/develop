Report finder

What this shows

The whole report catalog on one searchable page — every transfer report, server report and dashboard (title and introduction lifted from the reports themselves) plus the analyses pages. Type in the box and the list narrows as you go; click a title to open the report.

How the search works

The query is matched against each report's title, its introduction text (the paragraph right below the title on the report page), its keywords (the muted line under the introduction) and its page file name (so e.g. went-kaput finds the "Trouble after Success" report). A title match weighs more than any other match: reports whose title matches are listed first, then the reports matched through their introduction, keywords or file name — each group keeping the catalog order. The search grammar is the site-wide one: ? matches one character, * any run of characters, and the whole-word operators or, and and not combine terms (e.g. failure and not heatmap).

This page finds reports; to find an entity (an account, subscription, login, host, partner, application, domain or IP), use the magnifier next to the Entities link on the left of the top bar instead.
