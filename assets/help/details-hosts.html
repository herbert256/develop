Host details

What it shows

  • One page per remote host — a configured endpoint, or an address we connected out to — opened from every Remote Host cell. Title prefix = connection/movement direction.
  • Activity per day (Date · Files · Error · OK · Volume · Duration), Logons and Features side by side. Features: the Remote Host first, its IP address(es), then each single linked Partner, Domain, Logical, BL, Application or Account.
  • Logons — Item · Value · Last. Inbound: First logon, Pattern, Number of logons, Allowed, Disallowed. Outbound: First connection, Pattern, Connections, then our failures there.
  • Outbound failure rows: Timeouts, SSH errors, Network errors, TLS handshake, Too many connections, SSH negotiation, Proxy errors, and Auth failures split into Password, Key, Certificate, Other.
  • Subscriptions — Subscription · Direction · Files · Error · OK · Volume; a nonzero Error opens Failed files for that subscription.
  • Last error(s) — Date & time · Subscription · File: per subscription with a failed File, its newest one; the whole row opens that File’s page.
  • Outgoing connections — IP · In · Out · Name: the host as configured endpoint plus the hosts seen; In / Out = Files that entered / left us. Rarely also Incoming connections (IP · In · Out).
  • Accounts (Account · Login · Host · Files · Error · OK · Volume); Domains, Applications, Logical, Partners, BL when there are several (a single value folds into Features).
  • Load by weekday / hour (Files · Error · OK · Volume); Dwell (Files per store-and-forward wait, with Share).
  • Duration per leg (min, avg, max, p50, p95, p99 of the OK legs), Size (Volume, Throughput, Average, Largest), Date (First / Last seen, Busiest day, Active days), Ranking (position among all remote hosts; each row opens Ranking).
  • Last server log messages (its 25 newest lines) and Last server log errors (its newest 10 Error and 10 Warning lines, plus those of its 1-to-1 connected entities after its last transfer).

Rules

  • Page background = the host’s result colour: red when any connected subscription is red, green when all are green, else orange; a host no subscription names goes by its own last File (see Generic help).
  • Logons sum over the host’s addresses; zero rows are left out, failure rows are red. The outbound figures match Partners Out.
  • Counts are Files (Error = Failed or Expired). Subscriptions and breakdown rows take the linked entity’s result colour.
  • Connection rows: green configured with traffic, red traffic on an unconfigured address, orange configured without traffic (folded behind one orange row).
  • An Error line newer than the end of its last transfer raises the red ERRORS IN SERVER LOG AFTER LAST TRANSFER banner.
  • No date filter: full period. A never-seen page keeps Features, Subscriptions, Accounts and Outgoing connections.
