Only red

What this shows

The never-worked list: subscriptions whose every File is an Error — outcome Failed, or Expired — with not a single OK delivery in the whole log window. Where From green to red lists the flows that used to work and broke later, this page lists the flows that never worked at all: dead configurations, wrong endpoints, credentials that never matched, or flows abandoned right after setup.

Per subscription: its Files (all of them errors), the Failed / Expired split, the first and last failure, how many days it has been failing (first failure to the dataset's last day) and the volume of the failed attempts. The most recent failure sits on top — those flows are still actively trying and failing; entries whose last failure is long past are more likely abandoned. Click an Error count for that subscription's 10 most recent failed Files.

How it's computed

One pass over the logical transfers (Files, the delivered outcome) per subscription. The outcome split is the site-wide rule: Error = Failed or Expired (a staged UC2 file the retention sweep deleted before any pickup), OK = Processed or Waiting (staged and still collectable). A single OK File disqualifies a subscription from this list — including a Waiting one, so a UC2 flow whose file simply has not been collected yet is not "only red".

Why the date filter is off

"Never delivered" is a whole-window property — a narrowed From/To range would fabricate entries (by cutting away the successful days). The page therefore always shows the full period, like From green to red and Failure Episodes.

How it relates to the other failure reports

From green to red is the exact complement: red now but green before. Failure Episodes shows every failure run with its Last OK column ("never" marks these flows). Failure rate answers "what share fails" for flows that partially work. The subscriptions here are red on the Entities pages and their detail pages by the same outcome rule; the counts can differ slightly from "never green" on From green to red — a subscription with one mid-day OK File never ended a day green, yet it did deliver once, so it is excluded here.
