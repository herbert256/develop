Application details

What it shows

  • One page per application — the middle part of the logical flow name, the grouping counted in the Applications row of the home page’s status table — opened from every Application cell. Title prefix = connection/movement direction.
  • Last error(s) — Date & time · Subscription · File: per connected subscription with a failed File, its newest one; the whole row opens that File’s page.
  • Features — the application first, then each single linked Account, Login, Host, Domain, Logical, Partner or BL.
  • Waiting/Expired — State · Files · First staged · Last staged.
  • Activity per day — Date · Files · Error · OK · Volume · Duration (average per delivered File).
  • Subscriptions — Subscription · Direction · Files · Error · OK · Waiting · Expired (when any) · Volume; a nonzero Error opens Failed files for that subscription.
  • Incoming connections (IP · In · Out) / Outgoing connections (IP · In · Out · Name) — the configured whitelist / endpoints plus the addresses seen; In / Out = Files that entered / left us; an IP opens its incoming connection page.
  • Accounts (Account · Login · Host · Files · Error · OK · Volume); Domains, Applications, Logical, Partners, BL, Logins, Hosts (name · Files · Error · OK · Volume) when there are several — a single value folds into Features.
  • Load by weekday / hour (Files · Error · OK · Volume); Dwell (Files per store-and-forward wait, inbound end to outbound start, with Share).
  • Duration per leg (min, avg, max, p50, p95, p99 of the OK legs), Size (Volume, Throughput, Average, Largest), Date (First / Last seen, Busiest day, Active days), Ranking (position among all applications; each row opens Ranking).

Rules

  • Page background = the application’s result colour: red when any connected subscription is red, green when all are green, else orange (see Generic help).
  • Counts are Files; Error = Failed or Expired. On a application used both ways, outcomes split into In - Error · In - OK · Out - Error · Out - OK by file movement.
  • Subscriptions and breakdown rows take the linked entity’s result colour; every configured name is listed, one without traffic here has no counts.
  • Connection rows: green configured with traffic, red traffic on an unconfigured address, orange configured without traffic (folded behind one orange row).
  • No date filter: full period. A never-seen page keeps Features, Subscriptions, the connection tables and the configured names.
