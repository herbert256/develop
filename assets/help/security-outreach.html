Security outreach

What it shows

  • The partner call list for the two deprecated connection-security values: who still connects with one, who already cut over, who runs a mixed fleet. All three tables cover the full period; a summary line closes the page.

Columns

  • Outreach list (first table) — Partner, Deprecated parameter, Transfers (every leg with that value), First seen, Last seen. Only pairs seen in the last 7 days; (none) = no partner attributed.
  • Upgrades in the window — partners that used a deprecated and a modern value of the same parameter: Upgraded to, Old last seen, New first seen, Cutover (the date, or mixed fleet).
  • Deprecated-parameter timeline — per value: Partners still on it (last 7 days), Partners in window, Transfers, Newest seen.

Rules

  • Public Key ssh-rsa = an RSA key signing with SHA-1, disabled by default since OpenSSH 8.8; the same key works with rsa-sha2-256/-512 (a software upgrade, not a new key). TLSv1.2 = legacy; TLSv1.3 is current.
  • Clean cutover: the modern value first seen on or after the deprecated value’s last sighting (same day counts). Mixed fleet: the old value kept appearing; those partners stay on the outreach list.
  • Outbound leg: the Public Key is the partner server’s host key. Inbound leg: the partner client’s authentication key.
  • A leg counts for every partner of its subscription plus its remote host’s partner.
