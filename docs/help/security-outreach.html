Security outreach

What this shows

Two SecurityParameters values are deprecated: Public Key ssh-rsa — an RSA key still signing with SHA-1, disabled by default in modern OpenSSH (the same key works with rsa-sha2-256/-512, so it is a partner software upgrade, not a new key) — and TLSv1.2, the legacy TLS version.

The outreach list names every partner seen with a deprecated value in the last 7 days of the window, busiest first. The Upgrades table shows who already moved: a clean cutover date, or "mixed fleet" when old and new values overlap in time — two partner systems, one still legacy.

On outbound legs the Public Key is the remote server's host key; on inbound legs it is the connecting client's authentication key — the fix sits on different partner systems. Partners follow the site-wide union attribution.
