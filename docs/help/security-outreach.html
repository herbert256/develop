Security outreach

What it shows

The partner call list for deprecated connection-security values — the outreach view of Security parameters: who still connects with a deprecated value, who already cut over, who runs a mixed fleet.

Sections

  • Outreach list — one row per (partner, deprecated parameter) seen in the last 7 days of the window, busiest first; Transfers = every leg in the window negotiated with that value. A partner that stopped earlier (a completed cutover) is not listed here.
  • Upgrades — every partner that used a deprecated and a modern value of the same parameter. A clean cutover shows its date: the modern value’s first sighting on or after the deprecated value’s last (same-day switches count as clean). Mixed fleet: the deprecated value kept appearing after the modern one started — several partner systems or keys, only some upgraded; those partners stay on the outreach list while the old value shows up.

Rules

  • Public Key ssh-rsa — an RSA key still signing with SHA-1; OpenSSH disables it by default since 8.8. The same key works with rsa-sha2-256/-512, so it is a partner software or config upgrade, not a new key.
  • TLSv1.2 — the legacy TLS version; TLSv1.3 is current.
  • On an outbound leg the Public Key is the remote server’s host key (the partner upgrades their server); on an inbound leg it is the connecting client’s authentication key (the fix is in the partner’s client software).
  • Partners follow the site-wide union attribution: a leg counts for every partner of its subscription plus the host-resolved one.
