Failed files

What it shows

Every File that ended in error, one row each, newest first: the Files the home page’s Error cells and the Top view’s Files/Error column count. A home Error cell opens this page narrowed to its day.

Columns

  • Subscription — links its detail page.
  • Date/time — when the File started.
  • Error reason — the classified fault, the same text as the Failed subscriptions lists and the error page title; Expired (not collected) for a staged File the partner never picked up; - when no rule applies. Opens the File’s error page when it has one.
  • CoreId — the File; links File Tracking where configured.
  • Filename — the name of the file.

Rules

  • Error = outcome Failed or Expired, the site-wide outcome policy. Each File counts on its start day, so a day’s rows equal that day’s home Error cell.
  • Row tint = the subscription’s result, the standard colours: light green last transfer OK, light orange configured but never seen, light red last transfer in Error, light blue surfaced only by the server log. A name the configuration lacks stays untinted.
  • From/To narrows the rows; the search box filters them; 500 rows per page.
  • A subscription page’s Activity per day Error cell opens this page for that day and that subscription: the search holds the name in double quotes, which matches that exact subscription only.
