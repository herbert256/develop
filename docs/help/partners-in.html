Partners - Incoming

What it shows

One row per FE login (the credential a partner connects with): its use cases, logons, Files and pickups, plus the Incoming logon funnel (the SSH screening counts). Full-period; no date filter.

Columns

  • Login — links its detail page.
  • Use cases — UC2 (the partner picks up from us), UC4 (the partner delivers to us), UC2/UC4 (the mailbox pair).
  • Cloud / Gateway — the newest successful authentication on this platform / the last logon on the old gateway (input/logons_old.txt).
  • Files in / Files out — Files delivered to us / staged for pickup, whole transfer window.
  • Error — the Files that failed, delivered or picked up. Expired has its own column, so Error + Expired = the site-wide Error count.
  • Retrieved / Waiting / Expired — collected / staged, not collected yet / deleted by the retention sweep before pickup.
  • Oldest waiting — age of the oldest staged file against the newest transfer in the log; sorts by exact age.
  • Pickups — the pickup logons, taken once per login and account (an SFTP client opens several connections per visit).
  • Allowed / Disallowed / Authenticated / Locked — the SSH screening funnel per login, as on the Incoming logons page; click a count for its 5 newest log lines.
  • Auth Failed — the funnel’s Bad key + Key failures + Auth failed in one count; its drill holds the 5 newest lines of the three.
  • Pattern — the logon cadence (successful authentications over any protocol).

Rules

  • Rows = every configured FE login and every login named only by the old-gateway file, then the logins the funnel alone knows — empty transfer cells, no tint.
  • Use case of a subscription = the one UC derivation the whole site uses (its UC<n> prefix, else its configured pattern).
  • input/logons_old.txt: hand-maintained, one login per line then its stamp (FE000123  2026-09-02 14:35); blank and # lines ignored.
  • Tint = the login’s result: green delivering, red failing, orange configured, never seen. The funnel’s own screening colour is not carried; its red cells are. A 0 renders empty.
  • Not carried: the funnel’s No account, Session errors, Re-screens, First logon, Logons and Last logon (= Cloud) — see Logon.
