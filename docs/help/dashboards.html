Dashboards

What it shows

The Dashboard (top bar): the report data as graphs over the log window. Five KPI cards (Files transferred, Transfer failure rate, Volume moved, Server records, Server error rate) and one graph with twelve views: six per-slot activity, two cumulative coverage curves, four use-case status stacks.

Views

  • Duration — P50 / P90 / P98 duration of the slot’s OK Files, stacked dark green / orange / dark red bands (each top edge = that percentile). Fixed scale, equal ticks at 1, 2, 3, 5, 7, 10, 15, 20, 25, 30, 45 s, 1, 5, 30 m, 1, 5, 10, 24 h and ≥48 h (linear between; ≥48 h at the top), shared with the day pages.
  • Files processed — OK Files (Processed + Waiting) started in the slot.
  • Volume — bytes moved.
  • Error % Files — share Failed or Expired; no Files = a gap.
  • Transfer errors — raw Status Failed / Failed Subtransmission records: legs, not Files (one File can log several); none = a real zero.
  • PeSIT — CFT-link problem lines: ST→CFT red (outbound TM client leg), CFT→ST purple (inbound PESITD server leg); lines, not failed transfers.
  • Subscriptions seen, Partners seen — cumulative at each slot, four counts:
    • blue = seen in transfer + server logs (the union, always highest); orange = seen in the transfer log (the gap to blue = server-only).
    • green = latest File so far OK (delivered or waiting); red = latest File so far Failed/Expired.
    • Blue and orange only rise; green and red move both ways and always sum to orange.
    • Line draws all four; Bar/Solid stack red, green, blue without orange (the red/green boundary is the orange line, blue = the server-only remainder); the Data table lists all four.
  • UC1–UC4 status — the use case’s configured subscriptions stacked per slot: composition, not traffic.
    • The total is the configured count (no configuration history), so the top edge is flat. Green OK at the bottom, never-seen light orange on top, problem states between by severity — the report’s own verdict at each slot end.
    • UC1/UC3/UC4: OK · No result · No files · Server error · OK + error · Error · Not seen (UC1 never has No files); UC2: OK · Both · No files · Never collected · Nothing.
    • Titles link UC1, UC2, UC3, UC4; no configured subscriptions = no button.

Rules

  • Per view: Line / Bar / Solid switch, interval 1 h / 2 h / 4 h / 6 h / 12 h / 1 day, hover tooltip, Data table (always 6-hour), a title linking the best-fitting report. Style and interval are remembered for the session; the style follows to the day pages (own intervals 15 / 30 min / 1 h, remembered separately).
  • A From/To change picks a fitting interval (a day hourly, a week 4-hour, the full period daily); a manual pick overrides until the next change.
  • Each resolution is computed from the raw Files, never merged from a finer one (a median of medians is not a median).
  • A slot click opens that day’s page in the same view (30-minute slots). Cumulative and status views have no day view: their slots open the day’s Files processed graph; a day page opened elsewhere falls back to Duration.
  • Activity views: the logical-transfer cache; PeSIT: the PeSIT report’s classification. Cumulative views use the union partner attribution — the final orange matches First seen, blue its both-logs view; green/red follow the site-wide subscription rule (red when the latest outcome is Failed or Expired). The server log starts on its own date, so blue can lag orange early, then overtake.
  • Status stacks re-bucket each use-case report’s hourly verdict sidecar: a state, not a rate — a coarser slot takes its last hour, an empty slot carries the previous state; the right edge equals the report.
  • Busiest this period closes the page: the day pages’ six Top-5 tables (partners and subscriptions by Files, Volume, Errors), re-selected within the From/To range; no activity = a gap. Union attribution: at the full range they match the Entities view See more opens, sorted descending.
  • Opens at the full log period; no search box, full From/To controls. KPIs re-sum, the graph clips, Top-5 re-select; the range is remembered for the dashboards only, never carried to the reports.
  • Inline SVG, no external libraries or web fonts.
