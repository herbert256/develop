Dashboard

What it shows

  • Five KPI cards (Files transferred, Transfer failure rate, Volume moved, Server records, Server error rate), one graph with 16 views, and Busiest this period: the top 5 partners and subscriptions by Files, Volume and Errors.

Tabs

  • Duration — P50 / P90 / P98 of the slot’s delivered (Processed) File durations, nearest rank like the Duration report; stacked bands on a fixed scale.
  • Files processed (OK Files) · Volume · Throughput (MB/s over legs above 1 MB and 500 ms) · Error % Files (Failed or Expired) · Transfer errors (every non-Processed leg, not Files).
  • Connections (SSH / PeSIT sessions opened, by who dialled) · PeSIT (CFT-link problem lines, ST→CFT vs CFT→ST) · EventQueue (“Unable to submit event” lines).
  • Seen › Partners / Accounts / Subscriptions — how many were seen by then (orange), split green / red. Only a Failed last File counts red; Subscriptions also count server-log reds. Green + red = orange.
  • Use cases › UC1–UC4 — the configured subscriptions stacked by status per slot (UC1/UC3/UC4: OK · OK + error · Error · Not seen; UC2: OK · Both · No files · Never collected · Nothing).

Rules

  • Per card: interval 1 hour … 1 day, Line / Bar / Solid and, except Duration, Linear / Log. Remembered for the session.
  • From/To narrows everything: the KPIs re-sum, the graph clips, the top 5 cards re-select (See more opens the Entities view). A range change re-picks the interval to fit it; All returns to the page default (6 hours).
  • A slot click opens that day’s day page on a matching view; a Use cases slot opens its UC status report. A card title opens its report.
