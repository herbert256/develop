Dashboard

What it shows

  • Five KPI cards (Files, File error rate, Volume, Server records, Server error rate), one graph with 16 views, and Busiest this period: the top 5 partners and subscriptions by Files, Volume and Errors.

Tabs

  • Duration — P50 / P90 / P98 of the slot’s delivered File durations, nearest rank like Duration.
  • OK Files (Processed + Waiting) · Volume · Throughput (MB/s over legs above 1 MB and 500 ms) · Error % Files (Failed or Expired) · Transfer errors (every non-Processed leg, not Files).
  • Connections (sessions opened, by who dialled) · PeSIT (CFT-link problem lines per direction) · EventQueue (“Unable to submit event” lines).
  • Seen › Partners / Accounts / Subscriptions — how many were seen by then (orange), split green + red (a Failed last File; Subscriptions also server-log reds).
  • Use cases › UC1–UC4 — the configured subscriptions stacked by status per slot (UC1/UC3/UC4: OK · OK + error · Error · Not seen; UC2: OK · Both · No files · Never collected · Nothing).

Rules

  • Per card: interval 1 hour … 1 day, Line / Bar / Solid and, except Duration, Linear / Log. Remembered for the session.
  • From/To narrows everything: the KPIs re-sum, the graph clips, the top 5 cards re-select (a name opens its detail page, See more the Entities view). A range change re-picks the interval; All returns to 6 hours.
  • A slot opens that day’s day page (a Use cases slot its UC status report); a card title opens its report.
