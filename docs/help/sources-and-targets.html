Sources and Targets

What it shows

The From/To folder paths configured on every subscription, and where they overlap. One row = one subscription using one path.

Sections

  • Values used as both a Source and a Target — a path one subscription writes to and another reads from: an internal hand-off (a relay through a shared folder). Role says, per subscription, source or target.
  • Sources used by multiple subscriptions — one block per source folder read by two or more subscriptions.
  • Targets used by multiple subscriptions — one block per target folder written by two or more subscriptions.

Rules

  • Source and target are the From and To rows of the subscription’s detail-page Features table.
  • A path on a remote partner (an endpoint SecureTransport dials) shows the host after an @, e.g. /some/dir @ sftp-test.lifetime.nl — exactly as on the Search page. A local SecureTransport path (e.g. F:\Data\Cloud\in\…) has no host.
  • The host is appended to whichever side is remote (from the configured remote host and file-movement direction): the source on a pull flow, the target otherwise.
  • Error / OK per subscription are its own transfer outcome.
  • Each row links to the subscription and is tinted by its status (green / red / orange).
  • A configuration analysis over subscriptions.json: no From/To date filter.
