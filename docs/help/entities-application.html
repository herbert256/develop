Applications

What it shows

One row per internal application — the identities of the Applications row on the Logical, Partners, Domains & Applications page. Columns, rules, views and drills are the same on all nine entity pages: see Entities.

How a File is attributed

  • The application is the MIDDLE part of the three-part logical name domain_application_partner (ODV-TDRS-ASR → TDRS); a File under a two-token name (no application segment) is not counted.
  • A File counts for every application its subscription maps to (the FlowID spine), unioned with the parse-time attribution; the total row counts each File once.
