What it shows

  • Which pairs of the nine entities (Account, Login, Subscription, Remote host, Logical, Partner, Application, Domain, BL) belong together: every pair seen on one transfer-log row, plus the configured pairs that never logged. Relationships only — no counts, no date filter.

Columns

  • first entity · second entity — one row per pair, names linking their detail pages; a repeated first value is blanked, so one entity’s pairs read as a block. The total row counts the pairs.

Rules

  • Under the Configuration row, the second tab row picks the first entity, the third row the second; each grays out the other’s pick. Swap opens the same pair of types the other way round.
  • Seen = both values on one log row, anywhere in the loaded logs; a leg inherits its File’s partner, application, domain, logical and BL.
  • A pair with a blank side — blacklisted or unattributed — is not listed.
  • Each cell tints by its own entity’s result colour (see Generic help).

Tips

  • A configured pair that never logged is a flow without traffic, or a spelling that never matches.
