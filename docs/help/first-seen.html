First seen

What it shows

For six entity types — Logical, Partners, Subscriptions, Accounts, Logins, Hosts — the calendar day each configured name was first seen in the transfer logs: one row per day in the loaded logs, a blank cell = nothing of that type was new that day. The first day of the logs is naturally the largest row.

Rules

  • The summary rows use the same Seen / Not seen split as the home page’s status tables (the coverage universe), so the figures always agree. Per column: Seen + Not seen = Total (every configured name of that type); the day rows + “Seen, no date” = Seen.
  • Seen, no date = seen without a dated transfer of its own: a UC3 subscription whose polling works but never had a file to fetch, a name whose transfers are credited to a sibling (a shared endpoint’s co-tenant, one organisation of a two-partner account), or a blue name without a dated cross-reference.
  • Two views: Transfer log only (default) = the status tables’ Transfer scope — a server-log-only (blue) name counts as Not seen. Both Transfer & Server logs = the +Server scope, and dates the blue names (the Status tables’ Server column, the Seen in server log set).
  • A blue name never transferred, so it takes the oldest first transfer of its cross-referenced entities (its account, subscription, login, host or partner in the FlowManager configuration) as the day its flow became active; cell pages tag those rows Server in the Log column.
  • The raw server log is deliberately not scanned for mentions: nightly File Maintenance names virtually every account and would move everything to the first day. A blue name whose cross-references never transferred sits in “Seen, no date”.
  • The split is read from the coverage tables (the files behind the home status tables and the Entities views); dates come from the transfer parse caches — accounts and partners per File, subscriptions, logins and hosts per log record.
  • Matching is exact, case aside; subscriptions match by prefix (a configured subscription matches the logged site values it prefixes).

Tips

  • Every count opens a cell page listing exactly the items behind it: the name (linked to its detail page), its configured direction (blank when not configured), its first transfer timestamp.
  • Cell-page tints: light green last transfer OK, light orange configured but never seen, light red last transfer Error (or server-log errors after it), light blue server log only.
