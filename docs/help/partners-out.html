Partners Out

What it shows

  • One row per host we connect out to: every configured host, every host we failed to log on at, every address we connected to. Full period; no date filter. Laid out like Partners in.
  • Views — Endpoint (per host), Accounts, Partners: the same table per entity the configuration pairs the hosts with. A host of several accounts counts for each (User names the account that failed), so rows can exceed the Total, which counts each host once; an unmapped address is left out.

Columns

  • Remote host links its detail page. Use cases: those of the host’s subscriptions, configured or seen trying.
  • Files In / Files Out — Count by movement (the Entities Remote Hosts figures), Errors the failed or expired ones.
  • Connections / Last connection — the connections we opened, over the host’s name and addresses.
  • Failed logons — User, Failures = Password + Key + Certificate + Other, Reason of the newest, First / Last failure day.

Rules

  • Row tint = the host’s result colour; an address or unconfigured host stays untinted. A 0 is empty. Sorted by Failures, then Connections.

Tips

  • Click a row with failures for its 10 newest failure lines.
