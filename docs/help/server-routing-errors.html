Routing errors

What it shows

  • The Advanced Routing lines where a route gives up on a file, one row per line, newest first. Four families:
  • Could not send file (AR0074) — delivery to the transfer site failed after its retries.
  • Publish to account failed (ARPA0001) — a received file could not be published into its account.
  • Post client action error (ARRC0009 and kin) — the action after a received file (typically deleting the source) failed.
  • Route stopped (ARSP0001) — a step failed and its configuration abandoned the rest of the route.
  • The summary line counts the lines per family and the rows shown.

Columns

  • Date & time, Error (the family), Code (the AR code).
  • Account or subscription — the subscription; for a post client action the account. Links its detail page; the row carries its result colour.
  • File — the file the line names.

Rules

  • A truncated or renamed subscription name resolves to its current configured name.
  • At most 1000 rows and 10 per family and entity, the newest; the summary counts every line in the log.
  • Unresolved Route stopped lines (no OK File since) feed the Deploy reason on the Entities Subscriptions Error view.

Tips

  • Error pages and the home Reason name these lines Duplicate file, Route stopped or Post client action failed; a recurring entity has a problem on that step.
