Day page

What it shows

  • One data day of both logs, opened from a home page Date cell or a dashboard slot; the arrows beside the title step a day.
  • KPI cards — Files, File error rate, Volume, Server records, Server error rate, each with its change against the same weekday’s average.
  • Graph — Duration, OK Files, Volume, Error % Files, Transfer errors, PeSIT, EventQueue in 15-, 30- or 60-minute slots (see Dashboard).
  • Server log problems this day / Transfer log problems this day — one line per signal with its count, linking its report.
  • Remarkable facts — only what stands out (a dominating account, the longest transfer, weekend activity…); an account links its detail page, a File with a File page opens it. Accounts that went quiet after the day show only on days more than 14 days before the newest one.
  • Busiest this day — the top 5 partners and subscriptions by Files, Volume and Errors; a name opens its detail page.

Rules

  • Transfer figures count Files, server figures log lines; both match the day’s Top view rows.
  • No From/To: the page is the day; its links open their report narrowed to the day where it follows a date.
  • Problem lines appear only when they apply. Server log: Server errors/warnings, Logon screening failures, Outbound logon failures, Connection failures, Route stopped, Event-feed errors, No remote dir, No remote files.
  • Transfer log: Files in error (opens those Files), One-legged Files, Went red, Never delivered, Waiting for pickup, Expired before pickup, Anomaly scan.
  • Partner figures count a File for every partner of its subscription; See more opens the Entities view narrowed to the day.
