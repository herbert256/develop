Anomalies

What it shows

  • Days and hours unlike their usual selves, side by side: Daily — unusual days (one row per flagged day and signal) and Hourly — unusual hours (one row per episode of flagged hours, paged).
  • The × typical cell is red at ≥10× typical, amber below it; on a silence (no ratio) the Value cell is red.

Columns

  • Date — opens the day page with the matching chart selected.
  • Hours (Hourly) — the episode’s time span, e.g. 07:00-07:59.
  • What — the signal: Error rate, Duration, Files spike, Files drop (daily), Silence or Volume.
  • Value / Peak — the flagged figure (a Files spike or drop counts the OK Files: Processed + Waiting); Peak = the episode’s worst hour.
  • Typical — the baseline: the median, or the rule’s floor when higher.
  • × typical — Value ÷ Typical.

Rules

  • Typical = the median over the window’s days (per hour of day for Hourly), weekdays and weekends apart; hours bucket by File start.
  • Hourly, each also ≥4× typical: Error rate ≥25% on ≥5 Files; Duration avg per delivered File ≥5 min on ≥5 delivered Files; Files spike ≥30 OK Files; Silence 0 Files where ≥20 are typical; Volume ≥100 MB.
  • Daily: Error rate ≥10%, ≥20 Files, ≥4×; Duration ≥5 min, ≥20 delivered Files, ≥4×; Files spike ≥100 OK Files, ≥2×; Files drop ≤¼ of a ≥100 typical (OK Files); Silence as hourly; Volume ≥200 MB, ≥2×.
  • Consecutive flagged hours merge into one episode, bridging a single calm hour.

Tips

  • On the newest day outbound legs may not be exported yet, flagging late hours as Error rate — recheck after the next export.
