Transfer Failure Rates

What this shows

Three tabs, each with the same four figures — Files, Error, OK, Error % — broken down a different way: per Account, per Destination Subscription, and per Day. All three count Files (logical transfers, from _files.tsv), so a transfer that failed on its first leg but was ultimately delivered by a retry counts as OK, not Error.

How it's computed

A File counts as Error when its final, last-chronological row did not deliver — this is the same "delivered" rule used everywhere logical transfers are split into Error/OK. An account or a transfer with no usable account/subscription value (blanked by the platform-internal blacklist) is kept in the totals under a parenthesized placeholder — (no account) or (no subscription) — rather than dropped, so the totals still reconcile.

The per-account and per-subscription tabs are sorted worst-first, by Error % then by volume of failures, so the flows most worth investigating surface at the top. The per-day tab is chronological instead, to show the failure rate trending over time.
