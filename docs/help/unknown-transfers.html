Unknown transfers

What it shows

  • Every File with an account but no subscription: no configuration match, cross-reference vote, direction rule or server-log session could place it. It reads subscription Unknown.
  • A routing gap to investigate: the Files count in every day, account, login, host and protocol figure, but no subscription table shows them.

Files

  • Date/time — the File’s start. Account, Login, Remote host link their detail pages.
  • Side — the connection side (In / Out); an Unknown File has no movement direction.
  • Legs, State (OK / Error / Waiting / Expired; opens the File’s own page when it has one), Volume, CoreId (links SecureTransport File Tracking), Filename.
  • Rows tint by the File colour: green, orange after a retry or resubmit, red for Error / Expired. Newest first, 500 rows per page.

Per account

  • Files, OK, Error (Failed or Expired), First and Last start per account.

Tips

  • Most rows need one config fix: give the account (or its login) the subscription it should run, or check the route the server log names on the File’s page.
  • These Files do not colour their account, login or host; the Skipped report lists the records without even an account.
