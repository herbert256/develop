Search

What it shows

One flat, searchable list of every name the site knows, with its Error / OK Files and when it last moved a file. The table starts empty; rows appear once you type a search term (syntax: General).

Columns

  • Type — Partner, Subscription, Host, Login, Application, Domain, BL, IP, Account, Source, Target, Whitelist.
  • Error / OK — the entity’s Files by delivered outcome (Files = Error + OK, so that column is omitted).
  • Server log — blank for the Logical / Partner / Application / Domain / BL groupings.
  • Last seen — ccyy-mm-dd hh:mm:ss of the newest File attributed to the entity; blank when it never moved a file (blue ones included).
  • Last seen for a Whitelist / IP row: the last transfer involving that address; a Source / Target row: its subscription’s stamp, a multi-subscription path the newest across them.

Rules

  • Searchable: configured (partners.json, subscriptions.json) and logged accounts, logins, hosts and subscriptions; the groupings; source and target paths; endpoint address aliases from input/ip/ip-hosts.tsv; every whitelisted IP.
  • No From/To filter: seen = anywhere in the loaded logs.
  • Type checkboxes: none ticked = every kind; ticking narrows. The IP box covers the resolved-host aliases and the whitelisted IPs. Every entity is listed, seen or not; the row colour is its status — no seen filter.
  • Green = last transfer OK (or, without a status, moved files); red = last transfer Error or server-log errors after the last OK; orange = configured, never seen or moved no files (zero counts, links the never-seen detail page); blue = server log only.
  • Groupings (Logical, Partner, Application, Domain, BL) count each File’s own attribution (the partner organisation; the application / domain segments of the account name), are seen when one File carries them, and link their detail pages.
  • Source / Target: a subscription’s From / To directory + file mask (its detail-page Features table); the row links the subscription with its Error / OK. A path on a remote partner appends the host after @ (/some/dir @ sftp-test.lifetime.nl).
  • A path shared by N subscriptions collapses to ▸ <path> (N), counts summed; click to expand one linked row per subscription with its own counts.
  • Whitelist: one row per (allowing account, IP) from the AllowIP whitelists; an IP has no page — the row opens the allowing account’s detail page, once per account.
  • One raw-IP alias per configured endpoint address in ip-hosts.tsv, unless already a host entity or Whitelist row; it links the endpoint’s host detail page when known.
  • No drill-downs: for an entity’s 10 most recent transfers open its detail page or the Seen reports.
