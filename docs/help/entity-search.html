Search

What it shows

  • One searchable list of every name the site knows, configured or logged. It starts empty; rows appear as you type (syntax: Generic help).
  • Twelve type boxes narrow the search: Logical, Partner, Subscription, Account, Host, Login, Application, Domain, BL, IP, Source, Target. None ticked = every type.

Columns

  • Name — links the detail page. Direction — the connection/movement pair of that page.
  • Type — as above; Remote Host is the Host box, Remote Host (IP) and Whitelist the IP box.
  • Error / OK — the entity’s Files by outcome.
  • Last seen — the newest File of the entity; blank when it never moved one.

Rules

  • Row colour = the entity’s result (Generic help); a row without one is green when it moved Files, else orange.
  • Source / Target — a subscription’s From / To directory and file mask (a remote one adds @ host), with that subscription’s counts and colour. A path shared by N subscriptions shows once as ▸ path (N); click to list them.
  • Whitelist — one row per allowing account and IP; it opens the address’s incoming connection page when it has one, else the account’s detail page. Remote Host (IP) — a configured endpoint address, linking its host when known.
  • No From/To filter and no drill-downs: open the detail page for the newest Files.
