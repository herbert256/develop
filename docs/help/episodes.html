Episodes

What it shows

  • Failure runs in time per subscription: consecutive Files in error collapsed into episodes, each ended by the next OK File or still open — how often a flow breaks and how long it stays broken.

Tabs

  • Episodes — per failed subscription, most episodes first: Files, Error, Episodes, Longest run, its closed episodes by time to recovery (Healed <= 1 h, 1 - 24 h, Over 24 h), Last OK (never = no OK File in the window).
  • Below it, Time to recovery: all closed episodes by Recovered within (5 minutes, 1 hour, 24 hours, 3 days, longer), Episodes, Share.
  • Recovered flows — subscriptions green again after a red episode (its own help).

Rules

  • Files are walked chronologically per subscription: a File in error (Failed or Expired) after an OK one, or at the start, opens an episode, the next OK File closes it; recovery time = first failure to that OK.
  • A run with no OK File yet is still open and not in Time to recovery; what is broken right now is on Failed Subscriptions.
  • Always the full period: a date range would cut runs in half.

Tips

  • Many quick-healing episodes = a flapping flow; few long ones = a flow that breaks hard.
  • Click an Error count for the 10 most recent failed Files. Retried and resubmitted Files: Retries & resubmissions.
