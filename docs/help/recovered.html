Recovered flows

What it shows

The good-news mirror of From green to red — did yesterday’s fix work?

One row per subscription whose latest File is OK but that went through a red episode earlier in the window: at least one day that ended on a failed File. Most recent recovery first.

Columns

  • Episode — the most recent run of consecutive active days that each ended on a failed File.
  • Recovered on — the first active day after the episode (by construction it ended green).
  • Outage days — the episode’s calendar span.
  • Error Files — the episode’s failures. OK Files — everything delivered since, to the dataset’s end.

Rules

  • Green when the latest File’s outcome is OK, red otherwise — the site-wide colour rule (Waiting counts as OK, Expired as Error).
  • A day with a failure but a later OK stays green, matching From green to red.
  • Only a subscription’s most recent episode is shown; an earlier, already-recovered one is not.
  • Always the full period, no date filter: the flip back is a sequence in time, a narrowed range would fabricate or hide recoveries.

Tips

  • Click the Error count for the episode’s 10 most recent failed Files, the OK count for the freshest successes since — the fastest way to confirm a fix actually took.
