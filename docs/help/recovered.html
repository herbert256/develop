Recovered flows

What it shows

  • The good-news mirror of Failed Subscriptions — did yesterday’s fix work? One row per subscription whose latest File is OK but that went through a red episode earlier in the window. Most recent recovery first.

Columns

  • Red from / Red until — the most recent episode: a run of consecutive active days that each ended on a File in error.
  • Outage days — the episode’s calendar span.
  • Error Files in episode — its failures. OK Files since — everything delivered after it, to the end of the data.
  • Recovered on — the first active day after the episode (by construction it ended OK).

Rules

  • Rows tint by the subscription’s current result colour.
  • A day ends red when its last File is Failed or Expired; Waiting counts as OK. A day with a failure but a later OK File is not red.
  • Only a subscription’s most recent episode is shown.
  • The episodes are worked out over the whole window (the flip back is a sequence in time). From/To shows the episodes whose Red from
  • Always the full period: the flip back is a sequence in time, a narrowed range would fabricate or hide recoveries.
    • hellip; Recovered on span overlaps the range, each with its full-period figures.

Tips

  • Click the Error count for the episode’s 10 most recent failed Files, the OK count for the freshest successes since — the fastest way to confirm a fix took.
