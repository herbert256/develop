BL

What it shows

  • One row per BL, in the shared Entities layout.

Rules

  • A BL comes from a configured subscription: a tags entry starting with BL (kept verbatim), a BL number in its description (BL, an optional space, _ or -, three or more digits; shown as BL<digits>), or a row of input/BL.txt.
  • A File counts for every BL of its subscription, so the rows can add up to more than the Files; the Total row, narrowed dates included, counts each File once.
