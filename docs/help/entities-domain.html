Domains

What it shows

One row per business domain — the identities of the Domains row on the Logical, Partners, Domains & Applications page. Columns, rules, views, scope and drills are the same on all nine entity pages: see Entities.

How a File is attributed

  • The domain is the FIRST part of the three-part logical name (AB, ODV, ZG, APS, …); single-valued, so a File never doubles; a File under a single-token name (no domain segment) is not counted.
