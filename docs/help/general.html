Generic help

Terminology

  • File — one logical transfer: every log row sharing a CoreId (inbound leg, outbound leg, retries), counted once. A File started under 10 minutes before the newest transfer is still under way: it waits for the next export.
  • Transfer — one log row (a leg). Per-leg reports (protocol, security parameters, AV scan) count Transfers and say so.
  • OK — the File’s final status is Processed or Waiting. Error — Failed (incl. Failed Subtransmission) or Expired.
  • Entities — subscriptions, accounts, logins, hosts, logical flows, partners, applications, domains, BL.

Colours

  • Green — the subscription’s last File is OK (Waiting counts as OK).
  • Red — its last File Failed, or the server log reports errors after it (incl. a UC3 that cannot connect on 3 polls in a row).
  • Orange — never in the transfer log, or its last File Expired. Untinted — not configured.
  • Other entities: red when any connected subscription is red, green when all are green, else orange.
  • A File row (every table of single Files): green = OK; orange = OK after a retry (a failed leg) or a resubmit, or UC2 Waiting; red = Error or Expired. The counts still take Waiting as OK.
  • Cells: red = an Error / Expired count, amber = Retry / Resubmit / Waiting; an empty cell is zero.

Top bar

  • Environment name (the home page).
  • Entities — the Subscriptions page; Files — All files search (their own group, right after the environment name). Overview — the Transfer top view; Errors — Failed Subscriptions; Duration — Duration; Partners — Partners in (its first row links Partners Out); Waiting/Expired — Waiting & Expired; Security — Security Parameters; Seen — First seen; Configuration — Configured subscriptions; Use cases — Use cases; Activity — Activity per week; Each opens its report group; the group’s other reports are one click away in its first row of buttons.
  • There is no Reports pulldown, Reports start page or Site map (since 2026-09-30): every report group opens from the top bar, the group’s other reports from its first row of buttons.
  • Dashboard — the graphical overview.
  • 🔍 Search · ? the page’s help (the two icons at the right). The home page ends with “Build on …”, the build report: how and when this site was built.

Tab rows

  • Up to three rows under the title: the report’s group members first (← Group after the title names it), then its own tabs and views; each combination is a bookmarkable page.

Search box

  • A page with a table over 25 rows gets one box filtering every table. ? = one character, * = any run, "…" = the whole cell; a space means AND; and / or / not combine terms (RABO or SAP, ABC and not XYZ).
  • Search and sort are remembered per report for the session; the Entities pages share one sort, every key of it, for an hour.

Date range (From / To)

  • All · Week / 4 weeks (the last 7 / 28 full days; hidden when the data is shorter) · Month (one calendar month back from the newest data day; always shown).
  • Current month / Previous month (every data day of that calendar month; hidden without data) · First day / Last day · Previous day / Next day (on a one-day selection).
  • Narrowing re-sums the figures in the browser, shared across an area for the session; Top views and Entities open at the full period.
  • A table that cannot follow the range says so; one left empty says “No rows in the selected date range”.

Tables

  • Sorting — click a header, again to reverse; Shift-click adds a key; a paged table returns to page 1.
  • cols (last cell of the total or last row) — hide or drag-reorder columns; Reset restores them.
  • csv (upper-right of the last header cell, on hover) — the table as shown, totals left out; a grouped header carries its group (“Files Error”).
  • Drill-downs — dotted-underlined counts expand to their 10 most recent Files, newest first, over the full period. A CoreId that has a File page (per subscription the newest OK File and the three newest Error Files, or one of the Longest Files) opens it.

Page tools

  • A CoreId links SecureTransport’s File Tracking (where it opens a site page, the ↗ after it does); ⧉ copies it.
  • Hover a date for “3 days ago”, from your clock.
  • Site links (“Back to …” too) open in the same tab, external ones in a new tab.
