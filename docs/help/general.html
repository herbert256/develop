Shared Concepts

Terminology

  • Sources: the transfer log (every file movement) and the server log (the platform’s info/warning/error messages).
  • File — one logical transfer: all rows sharing a CoreId (Inbound partner→ST leg, Outbound ST→CFT leg, retries), counted once, volume once: files moved, not log lines. E.g. 3 files retrieved from a partner = 3 Files, 6 rows, 4 sessions (one partner↔ST, three ST↔CFT). Files never exceed rows; equal only when every File has one leg.
  • Transfer — one physical row (a leg). Per-leg reports (protocol, direction/action, security parameters, AV scan) count Transfers and say so.
  • OK — the File’s final row is Processed (a failed retry then a success is OK), or Waiting (staged, still collectable). Error — any other status: Failed, the Failed Subtransmission variants, Expired. On Transfers reports each row counts by its own status.
  • Entities — nine types: subscriptions, accounts, logins, hosts, logical flows, partners, applications, domains, BL tags.

Colours

  • Row tint = the entity’s site-wide result: green last transfer OK; red last transfer Error (Failed, or Expired before pickup); orange never seen in this window, or mixed OK/Error across its subscriptions; blue server log only; untinted not in the FlowManager configuration. A non-subscription is green when all its subscriptions are, red when one is.
  • Cells: red = an Error / Expired count, amber = Retry / Resubmit / Waiting; empty = zero. Server-log lines: errors red, warnings amber.

Tab rows

  • Up to three under the title: the group members (sibling reports), the views (Details / Top view, All / Seen / Not seen …) and, on Entities pages, the scope: +Server (default) counts a server-log sighting as seen, Transfer does not. Every combination is its own page — bookmarkable, survives a reload.

Search box

  • Pages with a table over 25 rows get one box filtering every table across all visible columns. ? = one character, * = any run (FE?????, AB*); and / or / not combine terms (RABO or SAP, ABC and not XYZ, a leading not XYZ).
  • A space means AND unless an operator word is typed — then the query is taken as written (literal “and”: abc and and). Remembered per page for the session; a few tables are excluded (transfer patterns).
  • The Search page starts empty and searches every account, subscription, login and remote host as you type.

Date range (From / To)

  • Buttons: All; Week / 4 weeks / Month (last 7 or 28 full days, or one calendar month back; a newest day collected mid-day never counts); First / Last day; Previous / Next day (only when From = To, grayed at the ends).
  • Narrowing re-sums every visible number in the browser from embedded per-date figures. Remembered per session, shared across an area; Top-view pages reset to the full period on load. Figures that cannot re-aggregate (distinct counts) carry the note “⚠ The date filter does not adjust this table; values cover the full period.”

Tables

  • Sorting — click a header (numbers largest first, text A–Z), again to reverse; Shift-click adds a key (rank ², ³; shift-click again flips it); a plain click starts over. Remembered per report. Bar columns do not sort; range columns sort naturally.
  • cols (last cell of the total or last row) — untick columns; drag by the grip to reorder (mouse only), the total row follows; Reset restores the built order and all columns. Remembered per report; a report whose columns change restarts from its built order. Grouped header bands (Top view, home page) move within their group; hour×weekday heat maps and Boxes pages are fixed.
  • csv (upper-right of the last header cell, on hover) — the table as shown: filtered rows, current sort, hidden columns and totals left out; named <page>-<heading>.csv.
  • Drill-downs — dotted-underlined cells (Error/OK counts, the Seen and Search reports’ Server Log yes cells) expand to the 10 most recent entries, newest first, always full period.

Page tools

  • Ctrl+K / Cmd+K — the command palette: type part of a report name, keyword or entity name; arrows move, Enter opens, Shift+Enter opens a new tab, Escape closes.
  • ◐ in the top bar toggles the dark theme (light is default); remembered in your browser.
  • Every CoreId / transfer id carries ⧉: click copies it (a tick confirms). The id links to SecureTransport’s File Tracking (new tab); where the id opens a site page instead, ↗ after it opens File Tracking.
  • Hover a date (a cell, the “Generated on” line) for “3 days ago”, from your clock.
