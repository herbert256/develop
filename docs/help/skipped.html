Skipped

What it shows

  • What the skip list removed at parse time — accounts, subscriptions, logins and the log lines set aside with them. No other report, detail page or search counts them.
  • Five boxes: skipped accounts, subscriptions, logins, transfer log lines and server log lines.

Columns

  • Skip rules — Rule, then what it caught: Accounts, Subscriptions, Logins, Transfer log lines, Server log lines.
  • Skipped accounts / subscriptions / logins — the name and the Rule that caught it.

Rules

  • The rules are input/skip.txt, one token per line, this checkout’s own; edit it and rebuild.
  • Configuration names match on a case-insensitive substring (CRG matches IPO_CRG-OK01_RABOBANK); log records follow the rule kind (contains, exact or regex). A skipped login loses its detail page; to hide it from the server log too, use an any rule.
  • Records dropped for other reasons are listed where they belong: no subscription or account, or an http leg, on Unknown transfers; an empty ssh probe on One-legged.
