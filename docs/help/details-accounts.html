Account details

What it shows

  • One page per account, configured or seen in the transfer log, opened from every Account cell. Title prefix = connection/movement direction (IN/OUT; ? = unknown).
  • Features — the Account first, then each single linked Partner, Logical, Domain, Application, BL, Host or Login, and Twin (the same name spelled with the other separator, a different account).
  • Last error(s) — Date & time · Subscription · File: per connected subscription with a failed File, its newest one; the whole row opens that File’s page.
  • Waiting/Expired — State · Files · First staged · Last staged; a Files count opens Waiting & Expired.
  • Activity per day — Date · Files · Error · OK · Volume · Duration (average per delivered File).
  • Subscriptions — Subscription · Direction · Files · Error · OK · Waiting · Expired (when any) · Volume; a nonzero Error opens Failed files for that subscription.
  • Incoming connections (IP · In · Out) / Outgoing connections (IP · In · Out · Name) — the configured whitelist / endpoints plus the addresses seen; In / Out = Files that entered / left us; an IP opens its incoming connection page.
  • Logins, Hosts, Domains, Applications, Logical, Partners, BL — name · Files · Error · OK · Volume, when the account has more than one.
  • Load by weekday / hour (Files · Error · OK · Volume); Dwell (Files per store-and-forward wait, inbound end to outbound start, with Share).
  • Duration per leg (min, avg, max, p50, p95, p99 of the OK legs), Size (Volume, Throughput, Average, Largest), Date (First / Last seen, Busiest day, Active days), Ranking (position among all accounts; each row opens Ranking).
  • Files not picked up — Expired · File: files the server’s File Maintenance deleted uncollected from the account, newest 100. Rows red (Expired).
  • Last server log messages (the 25 newest lines of the account and its logins and hosts) and Last server log errors (their newest 10 Error and 10 Warning lines, plus those of its 1-to-1 connected entities after its last transfer); left out when it would only repeat the first table.

Rules

  • Page background = the account’s result colour: red when any connected subscription is red, green when all are green, else orange (see Generic help).
  • Counts are Files; Error = Failed or Expired. On an account used both ways, outcomes split into In - Error · In - OK · Out - Error · Out - OK by file movement.
  • Subscriptions and breakdown rows take the linked entity’s result colour; a configured value without traffic here has no counts.
  • Connection rows: green configured with traffic, red traffic on an unconfigured address, orange configured without traffic (folded behind one orange row).
  • An Error line newer than the end of its last transfer raises the red ERRORS IN SERVER LOG AFTER LAST TRANSFER banner; an account no subscription uses carries the amber NOT CONNECTED TO ANY SUBSCRIPTION banner.
  • No date filter: full period. A never-seen page keeps Features, Subscriptions and the connection tables.
