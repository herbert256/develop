Latest files search

What it shows

Every File on every subscription’s Latest files page, searchable from one page: up to 1000 per subscription.

Fields

  • File — matches the file name or the CoreId.
  • Subscription — matches the subscription name.
  • A filled field must match; an empty one does not narrow. With both empty nothing shows, and the line beside the fields counts what is searchable.
  • Case-insensitive. * = any run, ? = one character; several space-separated words must all match.
  • The results follow each keystroke; Enter searches at once.

Columns

  • Subscription — opens that subscription’s Latest files page.
  • Start, End, State, Direction, Size, Duration, File, CoreId — as on the Latest files page.

Rules

  • The first button row switches implementation: Implementation 1, period — the File search window pages; Implementation 2, latest 1000 — this page; Implementation 3, all files — the All files search.
  • The From/To selectors narrow the search to Files whose Start–End span overlaps the period, before the 500 cap; it is the shared transfer range, so it follows you from other transfer pages.
  • At most 500 matches are shown, newest Start first; the count line gives the full number.
  • A row is tinted by its File’s state: red Errored or Expired, orange Waiting, green Delivered.
  • The address keeps the search (?s= and ?f=), so a reload or a bookmark repeats it.
