UC status › UC2

What it shows

  • Every UC2 flow — we stage a file, the partner connects in and collects it — in three stacked tables: the status of each flow, what the partner’s visits did, and its pickups.
  • The other tabs: UC1 (we push out), UC3 (we poll and pull), UC4 (the partner delivers to us).

Columns

  • UC2 subscriptions — Status (Rules) · Subscription · Expired (files File Maintenance deleted from the account’s folder) · First / Last (when the app first and last staged a File) · Pickups / Last pickup (successful partner SSH logons). Boxes count the five statuses.
  • Visits per UC2 subscription — Pickups (the logons) · Collected · Collected + delivered (a two-way visit) · Delivered only (a UC4 delivery, never a pickup) · Same connection · Files picked up · Pickup pattern.
  • Logons group into visits (a gap over 30 minutes starts a new one); Same connection counts SSH sessions that provably both delivered and collected.
  • Pickups per UC2 subscription — the detail pages’ Pickup information collated, most Waiting first: First pickup / Last pickup · Last Gateway · Pickups · With files · Files picked up · Waiting · Oldest waiting · Expired · Pattern.
  • Last Gateway = the login’s last logon on the old gateway (logons_old.txt; — when not named); With files = pickups that collected a file; Pattern = the pickup cadence.

Rules

  • Never collected (red) — staged files expired and nothing was ever collected; logons alone do not count.
  • No files (orange) — the partner logs in, but the app never staged a file: a dormant or broken source side.
  • Both (green) — the partner provably collects (Files in the transfer log), yet some files still expired. OK (green) — collected, none expired.
  • Nothing (plain) — no collection, no expiry: a quiet flow, a partner collecting over CFT (no SSH pickup logged), or only empty-handed visits.
  • Uncollected detection rests on the retention delete, not on arrival: CFT collectors never log an SSH pickup. No files and OK need that SSH signal, so a CFT partner without expiry lands in Nothing.
  • Pickup and visit figures are the pickup account’s (with several FE logins, the flow’s own login’s) and repeat on each of its UC2 subscriptions; Totals count them once. File figures are each subscription’s own.
  • Rows carry the subscription’s result colour; all three tables are the current state, a date range does not narrow them.

Tips

  • An uncollected flow fails silently — nothing errors, the file expires. High Expired, a recent Last and no pickups is a live flow to chase; check the Disallowed logons on Logons.
  • Drills: an expiry row lists the maintenance deletes; No files and OK rows the partner’s recent pickup logons.
