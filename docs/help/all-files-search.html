All files search

What it shows

  • Every File of the transfer logs, searchable from one page by File (file name or CoreId) and Subscription; a filled field must match.

Columns

  • Start · Subscription · State (OK, Error, Waiting, Expired) · Size · File · CoreId.

Rules

  • Results follow as you type (Enter at once), case-insensitive: * = any run, ? = one character, space-separated words must all match. From/To limits the days searched.
  • Only the days that can hold a match are loaded, newest first; a pasted CoreId finds its day at once. The search stops at the newest 500 matches.
  • The line beside the fields counts the matches, the subscriptions, the days searched and the days the index skipped.
  • Row colour = the File colour: green OK, orange OK after a retry or resubmit and Waiting, red Error and Expired.
  • A File with its own page opens it from anywhere on the row; any other row opens its subscription.
