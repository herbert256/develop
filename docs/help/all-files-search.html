All files search

What it shows

  • Every File of the transfer logs, searchable from one page by File (the file name — the CoreId is shown, not searched) and Subscription; a filled field must match.

Columns

  • Start · Subscription · State (OK, Error, Waiting, Expired) · Size · File · CoreId.

Rules

  • Results follow as you type (Enter at once), case-insensitive: * = any run, ? = one character, space-separated words must all match. From/To limits the days searched.
  • The search starts once the first word has 3 characters (wildcards not counted) — the first word of File, or of Subscription when File is empty; the words after it may be shorter.
  • Only the days that can hold a match are loaded, newest first. The search stops at the newest 500 matches.
  • The line beside the fields counts the matches, the subscriptions, the days searched and the days the index skipped. With both fields empty it reads N files in M subscriptions for the From/To period, straight from the search index (the Files of subscription Unknown count, Unknown is no subscription); a day’s data file is only loaded when a search needs it.
  • Row colour = the File colour: green OK, orange OK after a retry or resubmit and Waiting, red Error and Expired.
  • A File with its own page opens it from anywhere on the row; any other row opens its subscription.
