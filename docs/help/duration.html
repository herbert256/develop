Duration

What it shows

  • How long Files take: the per-day table and, beside it, the Duration distribution of the same Files; the summary line: Files, median, p95, p99, max.
  • Two views: Delivered Files (the default) and All Files (every File with a measured duration); each shows its own distribution.

Columns

  • Duration per day — percentiles — Date / Files, then Average / Median, then p10 / p25 / p50 / p75 / p90 / p95 / p98 / p99 / p100: p95 = 95% of the day’s Files finished at or below it; p100 = the longest.
  • Duration distribution — Duration bucket / Files / Share, seven bands from <= 100 ms to > 30 min.

Rules

  • A File’s duration is its wall-clock span, first record start to last record end: the store-and-forward gap and retry idle time included, not the sum of the record durations.
  • Delivered Files leaves out the Error Files, whose span is how long they ran before giving up; in All Files a failure counts as long as it ran, so its p100 can far exceed the Delivered view’s.
  • Percentiles use the nearest-rank method; Median is p50. They are not additive: a narrowed date range keeps the day rows but blanks them in the total row; Files and the distribution re-total.

Tips

  • A gap between p99 and p100 shows how far the worst case sits from the rest; Longest Files names them.
  • The slowest flows: the Entities Subscriptions page sorted on a Duration column.
