What this shows

What changed on the newest data day: D is the latest date across the transfer and server parse caches, and every table is judged against D or D-1 — exports arrive in batches, so a change late yesterday may only surface in today's export.

New red flips lists the freshest breakage (evidence stamp or newest failing File on D/D-1; a chronically failing flow stays listed, its old Failing-since gives it away). Newly quiet catches flows the moment they cross the went-quiet 7-day rule; Recovered shows broken flows whose first OK after their last failure landed since yesterday.

First seen reads the first-seen ledger; New unknown names lists the server-log-only sidecar names mentioned on D or D-1. The report catalog's changes live on What's new — this page is about the data.
