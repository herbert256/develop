Since yesterday

What it shows

What changed on the newest data day. D = the latest date across the transfer and server parse caches; every section is judged against D or D−1, because exports arrive in batches and a late change may only surface in the next export. This page diffs the data; the report catalog’s changes live on What’s new.

Sections

  • New red flips — red subscriptions whose server-log evidence stamp (blue/_redflip.tsv) or newest failing File is on D/D−1. A chronically failing flow stays listed; its old Failing since gives it away. From green to red tells the full story.
  • Newly quiet — flows whose last File is exactly 8 days before the transfer window end: Went quiet flags a silence over 7 days, so these crossed the line within the last data day.
  • Recovered — green flows whose first OK File after their last failure is on D/D−1 (Waiting = OK, Expired = Error).
  • First seen — configured logical flows, partners, subscriptions, accounts, logins and remote hosts whose first-ever File is on D/D−1, from the first-seen ledger (the per-day cells of First seen). A first sighting appears here once, then lives only there.
  • New unknown names — names the server log mentions with no transfer of their own (the data/unknown sidecars, the set that seeds the blue result colour), newest mention on D/D−1. A configured name is blue (server-seen, never transferred); an unconfigured one is a stranger knocking — Seen in server log has the full lists.
