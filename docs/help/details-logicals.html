Logical Flow Details

What it shows

The detail page of one logical flow: a FlowID family of the configured subscriptions condensed to one three-part name. A - inside a part marks parts the derivation combined; a fixed mapping in input/logical.txt wins verbatim.

Sections

  • KPI line — rank and share of traffic among all logical flows, failure rate, total volume, cadence, and processed-transfer performance where durations are recorded.
  • Last error(s) — directly above Features, only when a subscription it moves files with has an error: one row per such subscription, its most recent error, newest first, with date and time, subscription and file.
  • Features — a Partner, Application, Domain or Logical breakdown holding exactly one row is folded away into a Features row, keeping its link and colour. The first Features row is the Logical itself.
  • Activity per day.
  • Breakdowns — every dimension the flow’s transfers touch: subscription, account, login, remote host, domain, application, partner.
  • Latest Files and the load tables.

Rules

  • The Subscriptions table’s nonzero Error count opens Failed files for that subscription at the full date range: every failed File of the subscription, so a page that sees only part of its traffic can list more.
  • A file belongs to a logical flow through its FlowID attribution, unioned with its subscription’s configured logical(s).
  • Every count is in Files: one per logical transfer, split by its delivered (final-row) outcome, volume counted once per file.
  • The subscription / account / login / remote host tables are cross-referenced with the FlowManager configuration: every name configured for this flow is listed, seen or not — green rows have logged data, red rows are configured but never seen; each links its own detail page.
  • Every configured logical flow has a page, seen or not. Background: light brown = seen & in, light blue = seen & out, light gray = seen & both/unknown, light yellow = never seen & in, light orange = never seen & out, light purple = never seen & both/unknown.

Tips

  • Click anywhere on a Last error(s) row for that file’s error page: every transfer leg and the server log of the failure.
