Connection Failures

What this shows

Connection failures per subscription (the Transfer Site entity, displayed as "Subscription" throughout the site), taken from the server log's "Connection failure while <site> tried to connect …" ERROR messages — a data source separate from the transfer log. This report counts every failing subscription, including well-known ones that never show up in the transfer-side Missing Subscriptions report (that report only lists names absent from the transfer logs entirely).

How it's computed

The server truncates long subscription names in its log messages, so each logged name token is resolved against the transfer area's subscription list (data/transfer/reports/subscription.rpt): a token that is the unique prefix of exactly one known subscription is shown in full and linked to its detail page (Known subscriptions table); a token matching several subscriptions, or none at all, is listed as logged, unlinked (Unresolved subscription names table). Repeated failures toward one subscription usually indicate a retry storm against an unreachable partner.

Because this report reads the transfer subscription list as an input, it can only run after the transfer reports have produced it — if data/transfer/reports/subscription.rpt is missing, this report fails with an error asking you to run the transfer reports first.
