What it shows

  • Flow manager entities and Logical, Partners, Domains, Applications & BL — one status row per entity type.
  • The per-day table — every day of the loaded logs, newest first.

Columns

  • Status tables: Total · Seen (% in the transfer log) · OK (% green) · Error (red) · Warning (orange) · Ok (green).
  • Per day, newest first: Transfers — Ok · Error · Error % of the log rows (legs).
  • Files — In · Out (by movement, else by connection side) · Ok · Cured (OK after a retry or resubmit) · Error · Error %.
  • UC2 state — Waiting · Expired; Duration — p50 · p75 · p90 · p95 · p99 of the delivered (Processed) Files; First seen — new Partners · Subscriptions.

Rules

  • A status figure opens the Entities view it counts; the second table’s Total opens the configured list. Colours: Generic help.
  • Per day: Date opens the day page, Error that day’s Failed files, Cured the Recovered files, Waiting / Expired / Duration their reports, First seen that day’s list.
  • The red subscriptions are listed on Failed Subscriptions; the log exports (files, records, first / last record, holes) on the build report.
