Home

What it shows

  • Flow manager entities and Logical, Partners, Domains, Applications & BL — one status row per entity type.
  • The per-day table — the newest 14 days of the loaded logs, newest first — with the Errors table beside it.

Columns

  • Status tables: Total · Seen % (in the transfer log) · OK % (green) · Error (red) · Warning (orange) · Ok (green).
  • Per day: Files — Ok · Cured (an OK File that had a failed leg: retried automatically or resubmitted) · Error · Error %; Duration — p50 · p75 · p90 · p95 · p99 of the delivered (Processed) Files.
  • Errors — Subscription · Date/time (to the minute) · Reason of every red row of Failed Subscriptions (the orange ones left out), newest first.

Rules

  • A status figure opens the Entities view it counts; in the second table the Entity label opens the configured list and Total the Entities All view. Colours: Generic help.
  • Per day: Date opens the day page, Error that day’s Failed files, Cured the Recovered files, a Duration cell the Duration report; the Duration headings open it at the 14 days shown. No Total row.
  • Errors: a Subscription opens the File page the row opens on Failed Subscriptions (its detail page when there is none); the Errors heading opens the report.
  • The log exports (files, records, first / last record, holes) are on the build report.
