Subscription details

What it shows

  • One page per subscription, configured or seen in the transfer log, opened from every Subscription cell. Title prefix = connection/movement direction (OUT/IN).
  • A verdict: what its UC status tab calls the flow; a failing flow can add a red headline and a Next move line.
  • Activity per day — Date · Files · Error · Recovered · OK · Volume · Duration (average per delivered File). One row with Features and, on a UC2 flow, Pickup information.
  • Features — Use case, Twin (the same flow configured the other way), Remote host, Login, Account, Domain, Application, Logical, Partner, BL, Cron + Schedule, From / To; when they apply Status (why it is inactive), Latest OK / Latest Error (that File’s page) and Server log error.
  • Pickup information (UC2) — the pickup counts, stamps, waiting / expired Files and Pickup pattern.
  • Waiting/Expired — State · Files · First / Last staged.
  • Incoming / Outgoing connections — the configured whitelist / endpoints plus the addresses seen; In / Out = Files that entered / left us.
  • Files — every File, newest first, 25 per page (Previous / Next): Start · State · Size · File · CoreId; the total row counts them all.
  • Load by weekday / hour, Dwell (store-and-forward wait, inbound end to outbound start), Duration per leg (min to p99 of the OK legs), Size, Date, Ranking (opens Ranking).
  • Last server log messages (25 newest) and errors (newest 10 Error and 10 Warning lines, its own and its 1-to-1 connected account, login and host’s after its last transfer).

Rules

  • Page background = the result colour: green last File OK, red last File Failed or server-log errors after it, orange never seen or last File Expired (see Generic help).
  • Counts are Files. Error = Failed or Expired; Recovered = OK after a failed leg. A nonzero day Error opens Failed files.
  • An Error line newer than the end of its last transfer raises a red SERVER LOG AFTER LAST TRANSFER banner.
  • A pickup = a successful SSH logon by the pickup account; a gap over 30 minutes starts a new visit.
  • The Files table is built in the browser from the All files search data, loading only the days a page needs; rows tint green (OK), orange (OK after a retry or resubmit, Waiting) or red (Error, Expired); a File with its own page opens it from any cell.
  • Connection rows: green configured with traffic, red traffic on an unconfigured address, orange configured without traffic (folded).
  • No date filter: full period. A never-seen page shows the verdict, Features and connection tables only.
