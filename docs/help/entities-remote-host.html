Remote Hosts

What it shows

One row per remote host — the partner side of a transfer, an outbound endpoint we dial (the configured hosts of Out accounts). Columns, rules, views, scope and drills are the same on all nine entity pages: see Entities.

How a File is attributed

  • A File counts for a host only when it connects out; the source addresses of incoming connections are not hosts (they belong to the whitelist and incoming views).
  • Distinct (host, CoreId) pairs are counted, so the per-host counts can sum to more than the distinct total.
  • Host identity comes from the transfer cache plus the endpoint map input/ip/ip-hosts.tsv (address → configured host): FlowManager forward-resolves configured endpoints, the parse retains a newly seen outgoing address under its uniquely attributable endpoint. No reverse DNS. The map is a union, so an older logged address stays nameable after an endpoint moves.
