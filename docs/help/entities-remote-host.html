Hosts

What it shows

  • One row per remote host — an endpoint SecureTransport dials — in the shared Entities layout.

Rules

  • A File counts for every host its legs name, but only when it connects out; incoming source addresses are never hosts.
  • A File on two hosts counts for both.
  • Addresses are named through the configured-endpoint map (input/ip/ip-hosts.tsv); no reverse DNS, and an older address stays named after an endpoint moves.
