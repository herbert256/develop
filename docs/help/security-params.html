Transfer Security Parameters

What it shows

Connection security per attribute of the log’s free-text SecurityParameters column, in one table: Attribute (TLS version, Cipher, Cipher suite, MAC, Key Exchange, Public Key), Value and Transfers, each attribute’s values busiest first. Search an attribute to see only its rows.

Rules

  • The table counts transfers (legs), not Files: the parameters are negotiated per leg, so the Inbound and Outbound rows of one File can use different ciphers or versions.
  • Transfers = the OK legs; there is no Error/OK split and no green or red cells.
  • The attribute is labelled “TLS version”, not “Protocol”, to keep it apart from the transfer protocol — that distribution is the Protocol report in the same group.
  • A leg counts once per attribute, so Transfers does not add across attributes: the Total stays blank.

Tips

  • Click a value (a cipher, MAC, key exchange, public key, cipher suite or TLS version) for a page listing every subscription that used it, with its partner and transfer counts — each linking to its detail page — followed by a Partners summary rolling those subscriptions up per partner.
  • Those per-value pages are full-period, not date-filtered.
  • Deprecated values and who still uses them: Security outreach.
