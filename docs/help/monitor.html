Monitor

What it shows

The end-to-end monitor: a small file dropped on the CFT every 15 minutes travels through all four use cases with ourselves as the remote partner — out via the ST Edge across the internet and back in, twice — and ends up back on the CFT.

Three latency views cut each trip into disjoint segments, so an incident shows up in exactly the segment that owns it.

Views

  • Monitor CFT pickup — from the drop on the CFT (the timestamp in the name, monitor_ccyymmdd_hhmmss.txt) to the start of the inbound UC1 leg into ST: CFT directory pickup plus PeSIT delivery, the segment before ST. A slow CFT scanner shows here only. Healthy: roughly a minute.
  • Monitor duration — from entering ST (UC1 inbound leg) to the final hand-off to CFT (UC3 outbound leg), joined on the file name (the four monitor subscriptions share no CoreId): the whole loop — push to ourselves, UC4, CFT relay, UC2 staging, poll wait, collect. The UC3 poll fires at :05, so this view is floored at ~5 minutes; a file missing the first poll reads ~20.
  • Monitor staging — from entering ST to staged for pickup (the UC2 flow’s inbound routing leg): the delivery path without the poll wait. Shows ST-internal drift first. Healthy: 1–2 minutes; flat through a slow CFT scanner (pickup’s segment) and a dead poll (the loop view’s).

Rules

  • P50 / P90 / P98 percentile bands (dark green / orange / dark red) per slot on the fixed duration axis; Line / Bar / Solid styles; 4-hour to 1-day interval switch.
  • Each view has its own duration scale, fitted to its data: the loop view can never beat the ~5-minute poll floor, so a shared scale would flatten it.
  • Source: the transfer log’s monitor rows — files named monitor_ccyymmdd_hhmmss.txt on the UC1/UC2/UC3-INFRA_ST-MONITOR_INFRA subscriptions; earliest leg per side, so a retry never shifts a measurement.
  • Each resolution is aggregated from the raw measurements (a median of medians is not a median).
  • A file that never completed counts as 1 hour (or the slowest completed file, when longer), so losses stay visible in the percentiles. Exception: no end leg and younger than one hour against the newest monitor row — skipped, not penalised: the export was cut mid-flight.
  • Exists only where the transfer log carries monitor traffic; the top-bar Monitor link and this page appear and disappear with the data.

Tips

  • Clicking a slot opens that day’s page on its Files-processed view (day pages carry no monitor graphs).
  • The monitor itself (scripts, scheduling, CFT-side logs under e:\admin\monitor\9-logs) is documented on the CFT server in 8-docs.
