UC status › UC4

What it shows

  • Every configured UC4 subscription — we are the server, the partner connects in and delivers a file to us — one row each, worst status first; the boxes count the four statuses.
  • The other tabs: UC1 (we push out), UC2 (the partner collects from us), UC3 (we poll and pull).

Columns

  • Status — ok, error, ok -> error or not seen (Rules).
  • Subscription — the configured name; ↗ opens its detail page.
  • Files / OK / Error / Last file — its Files by outcome and the newest one’s date.
  • Logons — “successfully authenticated” lines, one per successful SSH logon; an “Allowed user” admission that then fails authentication does not count.
  • Arrivals — files actually handed over (“will be submitted for processing”).
  • Problems — logons the account whitelist refused (“Disallowed user”).
  • Last log — the newest line of those kinds: is the partner still knocking at all.

Rules

  • Roster: every configured UC4 subscription (by name prefix, else by its derived use case), run or not. Rows carry the subscription’s result colour (Generic help).
  • ok (green) — its last File is OK; Waiting counts as OK.
  • error (red, never an OK File) — its last File Failed, or the server log reported errors after it: nothing ever worked.
  • ok -> error (red after OK Files; a red box, like its rows) — the same red on a flow that has received before: a regression.
  • not seen (orange) — never in the transfer log; a flow whose last File Expired is orange and lands here too.
  • The server columns are keyed on the account: the partner connects to an account and the subscription name barely reaches the log. For UC4 the account–subscription pairing is one to one.
  • The whole table is the current state; a date range does not narrow it.

Tips

  • Inbound fails silently: a not-seen row with Logons but no Arrivals is a partner that gets in and never delivers; one with only Problems is turned away at the door (fix the whitelist).
  • A row’s drill lists its newest refusals first, then its newest logon and arrival lines.
