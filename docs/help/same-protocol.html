Inbound and Outbound same Protocol

What it shows

The Files whose first inbound leg used the same protocol as their last outbound leg — for example an SFTP upload that also left over SFTP instead of going on to the CFT.

Rules

  • Per File (one CoreId): the protocol of its inbound leg with the earliest start is compared with the protocol of its outbound leg with the latest start; the File is listed when they are equal.
  • Protocols as the transfer log names them: ssh (SFTP), ftp, pesit, routing.

Tables

  • Per subscription — per subscription and protocol: Files, OK, Error, the first and last day. Whole-window figures: From/To does not narrow this table.
  • Files — every File, newest first, 500 per page: the subscription, the File’s start, the protocol, the start of its first inbound and last outbound leg, its leg count, outcome, CoreId and file name. From/To narrows it; the search box filters it.
  • Rows tint by the subscription’s result: light green last transfer OK, light orange configured but never seen, light red last transfer in Error, light blue surfaced only by the server log.
