Notable Transfers

What this shows

Two tabs listing individual, standout Files (logical transfers): Largest — the top 50 by file size — and Slowest — the top 50 by total duration. Each row shows the file name, account, destination subscription, outcome, timestamp and throughput for context, so you can see exactly which transfer produced the extreme value.

How it's computed

Both tabs read the logical-transfer cache, so each row is one File — every physical row sharing that File (both directions, plus any retries) is already collapsed into a single size and a single duration before ranking. Size is the file's size (counted once, as everywhere else on the site). Duration is the sum of that File's row durations, not just one leg, so a transfer that needed several retries has its retry time included in "Slowest." Throughput is size divided by that summed duration.

Unlike most reports on the site, these two tables list individual transfers rather than aggregating by a dimension — there is no Error/OK split or percentage column here, only the outcome of each listed transfer.
