UC status › UC2: Pickups

What it shows

Every UC2 flow (the partner connects in and collects from us) on one row — the detail pages’ Pickup information tables collated.

Columns

  • First / Last pickup, Pickups — the pickup logons (date and hh:mm). A pickup = a successful SSH logon by the flow’s pickup account in the server log; logons group into visits (a gap over 30 minutes starts a new one); a visit that only delivered files (the account’s UC4 twin flow) is not a pickup.
  • Last Gateway — the flow’s login’s last logon on the old gateway, from the hand-maintained input/logons_old.txt (one <login> <stamp> per line, shown as written; the Partners - Incoming page reads the same file) through the subscription’s configured login(s); an em dash = the file does not name the login.
  • With files — pickup visits that collected at least one file of the subscription (each collected file credits the logon that took it).
  • Files picked up — the subscription’s collected Files (its OK figure). Waiting / Expired — its staged files by outcome.
  • Oldest waiting — how long the oldest staged, uncollected file has waited, one unit truncated (“5 days”, “12 hours”, “45 minutes”, “10 seconds”), aged against the newest transfer in the log so an unchanged export does not age between builds; sorts by the exact age; the Total row shows the oldest of all.
  • Pattern — the pickup cadence (“Daily”, “Every 15 minutes”, …; “Once” for a single visit, the spacing between two when too few for a median; “Irregular” when fewer than six gaps in ten fall within half and double the typical spacing).

Rules

  • The logon columns are the pickup account’s and repeat on each of its UC2 subscriptions — except on an account with several FE logins, where they are the flow’s own login’s (each login a different partner credential); the file columns are each subscription’s own.
  • A partner collecting over CFT/PESIT logs no SSH pickup: its logon columns stay empty while files still move. A 0 renders empty.
  • All figures come from the per-visit classification (the uc2-pickups sidecar) shared with the UC2 status report, the UC2 pickup visits analysis and the detail pages, so the four never disagree; the visit breakdown and the same-connection (UC4 drop) evidence live there.
