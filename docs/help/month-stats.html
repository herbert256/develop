Month stats

What it shows

One row per name of the chosen entity, counting the Files that started in the chosen calendar month. Two tab rows: the month (This month = the month of the newest File start in the data, Previous month = the one before) and the entity (Subscriptions, Logical, Partners, Accounts, Logins, Hosts, Domains, Applications, BL) — 18 pages.

Columns

  • Total files — Files (one per CoreId) started in the month.
  • In Files / Out Files — by the movement direction; a File with no known movement counts in the total only. A 0 shows blank.
  • Errors — Files that ended Failed or Expired (red).
  • Auto Retries — OK Files that carried a failed leg and no resubmitted leg: the platform’s own retry delivered them (amber).
  • Resubmit OK / Resubmit Error — every File an operator resubmitted (the log’s Resubmitted flag), by its final outcome.
  • Waiting / Expired — the UC2 Files staged but not collected yet, and the ones deleted unclaimed.

Rules

  • Source: the per-CoreId cache _files.tsv, its start date (col 4) picking the month; a File is attributed to each entity exactly as on the Entities pages (see each entity’s help page). The total row counts each File once, except for subscriptions, logins and hosts, where it counts (name, File) pairs.
  • Only names with at least one File in the month are listed; rows open busiest first. No From/To range: a page is one month.
  • An empty data set falls back to the calendar month.

Tips

  • Every name links its detail page; the search box narrows the rows. Sorting, cols, csv: Generic help.
