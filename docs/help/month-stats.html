Month stats

What it shows

  • One row per name of one entity type, counting the Files that started in one calendar month; busiest first, each name linking its detail page.
  • One tab row: the month — Current month (yyyy-mm) · Previous month (yyyy-mm) — then, after a separator, the nine entities (Subscriptions … BL): 18 pages.

Columns

  • Files — Files (one per CoreId) started in the month.
  • In Files / Out Files — by movement direction; a File without one counts by its connection side, so In + Out = Files.
  • Error — Files that ended Failed or Expired.
  • Automatic — OK Files with a failed leg and no resubmitted leg: the platform’s retry delivered them.
  • Resubmit Ok / Resubmit Error — every File with a resubmitted leg, by final outcome.
  • Waiting / Expired — Files staged but not collected yet, and those deleted unclaimed. Not on the Hosts pages: a host counts the Files ST sends out to it, and Waiting / Expired Files are pickups the partner connects in for.

Rules

  • Current month = the month of the newest File start in the data, not the calendar.
  • A File is attributed to names exactly as on the Entities pages; only names with a File in the month are listed.
  • The total row counts each File once, except for subscriptions, logins and hosts, where it sums the rows.
  • No From/To: a page is one month.
