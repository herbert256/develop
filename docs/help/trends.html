Trends

What it shows

  • Which flows are changing: the data window split at its midpoint and every subscription compared across the two halves, one tab per kind of change.

Tabs

  • Growers — Subscription / First-half Files / Second-half Files / Growth / First-half volume / Second-half volume: 4×+ more Files in the second half (20+ there); Growth new = no first-half activity, a flow that started mid-window.
  • Shrinkers — the same columns with Shrink: 4×+ fewer Files in the second half (from 20+ in the first), yet still active in the final week.
  • Slower / Faster — Subscription / Median (1st half) / Median (2nd half) / Ratio / Avg size (1st) / Avg size (2nd) / Files (1st / 2nd): Ratio 1.3×+ = slower, 0.7× or less = faster; biggest change first.

Rules

  • Files and volume count Files (logical transfers), each File’s size once.
  • Durations: only delivered (Processed) Files, the File’s wall-clock span (store-and-forward gap included), nearest-rank medians; a flow needs 15+ such Files in each half.
  • A flow that stopped altogether is on Went quiet.

Tips

  • Read the size columns first: a slowdown with the average size doubling is load growth; one at unchanged size is the interesting row.
  • A sudden speed-up can mean the flow now ships stubs — check the Size regime and Stub shippers tabs of Sizes & types.
