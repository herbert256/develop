From green to red

What this shows

The regression list: subscriptions that are red right now — their latest File failed — but that were green on an earlier day. These are the flows that used to work and are broken now, which makes them the most actionable failures on the site: something changed. Subscriptions that have never delivered an OK File are deliberately excluded — they were never green, so nothing flipped; Failure Episodes lists those with Last OK "never".

Per subscription: the last green day (the most recent day that ended on an OK File), the moment it went red (the first failure of the current run), how many days it has been red, the consecutive failures since, and its lifetime OK/Files counts. Newest flips first — the freshest regression sits on top. Click the Error count for the 10 most recent failed Files, the OK count for the last successful ones.

How it's computed

Logical transfers (Files, the delivered outcome) are walked chronologically per subscription. A subscription's color is the site-wide result rule: red when its latest File's outcome is Failed or Expired, green otherwise — Waiting (a UC2 file staged for pickup, not collected yet) counts as OK, Expired (the staged copy was deleted before pickup) counts as Error. A day "ends green" when the last File of that day is OK; the flip moment is the first failure of the run the subscription is still in. An OK and a failure on the same day leave that day red, so "last green day" and "went red on" can sit days apart. "Days red" counts to the dataset's last day, not today.

Why the date filter is off

The flip is a sequence in time — a narrowed From/To range would fabricate flips (by hiding the newest failures) or hide them (by cutting the green history). The page therefore always shows the full period, like Stale Accounts and Failure Episodes.

How it relates to the other failure reports

Failure Episodes shows every failure run (its Open incidents table requires 3+ consecutive failures and includes never-green flows); this page requires exactly one thing — green before, red now — and shows the flip itself, even when the current run is a single failure. Failure rate answers "what share fails", Not in Flow Manager covers configuration drift. The subscription's red tint on the Entities pages and detail pages follows the same latest-File rule this page uses.
