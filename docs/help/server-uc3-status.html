UC status › UC3

What it shows

  • Everything about UC3 — we connect out on a cron schedule and pull what the partner has waiting — in stacked tables.
  • The other tabs: UC1, UC2, UC4. Polling holds the same poll and schedule facts as one flat table.

Columns

  • UC3 subscriptions — Status · Subscription · Files / OK / Error / Last file · Polls / Empty polls (poll results; empty = no file found) · Problems (a connection failure or failed listing) · Last log (newest line of any counted kind, poll preparation included).
  • Polls by subscription — Polls · Empty polls (no file matched) · Files matched · Empty % · First · Last; worst first.
  • Remote directory listing failures — Listing errors · First · Last: the folder could not be listed at all (path, permissions).
  • Configured cronjobs — every receive schedule in the configuration: Cron expression (Quartz, raw) · Schedule (plain English) · Observed · Polls · Active days. Boxes count schedules, SFTP, FTP and distinct expressions.
  • Schedules that never complete a poll — those whose Observed is -: Poll starts (setup lines on the scheduled minutes) · Failure lines · What goes wrong (the dominant one: timeout, handshake, authentication, listing).
  • Missing remote directories + Missing remote directories per day (only when logged) — listings answered No such file, still open: Last error · Remote directory (every rejected path as logged) · Last OK File · Last good poll · Errors.
  • UC3 subscriptions that never find a file + Polls that found no file, per day — never-transferred UC3 flows whose every poll found 0 files: Last · Polls · Days · First.

Rules

  • Rows carry the subscription’s result colour. ok green: last File OK. ok -> error: red after OK Files, a regression (its box red too).
  • error red, never an OK File: last File Failed, server-log errors after it, or no connection on 3 polls in a row.
  • not seen orange: never in the transfer log (or last File Expired) — a UC3 polling cleanly with nothing to fetch stays here.
  • Observed: the median of each day’s first poll ± one standard deviation, or the poll rate above 3 a day; · files = only file arrivals give a slot; - = never observed; dark red = contradicts the schedule.
  • Authentication failures name only host and user, so they match through the configured host and can be shared by its flows.
  • A missing directory drops out once the flow recovers: a later OK File or successful listing of that site.
  • Never find a file leaves out flows that found files their pattern did not match — a pattern problem.
  • From/To narrows Polls by subscription, the listing failures, Missing remote directories and Never find a file (with their per-day tables); the other three tables are full-period.

Tips

  • A UC3 fails quietly, without transfer records: read Empty polls and Problems before chasing the partner.
  • A UC3 subscriptions row’s drill lists its newest problem lines first, then its newest poll lines.
