Config hygiene

What it shows

The configuration cleanup backlog: what is configured but pointless. Two kinds of findings, one row per object.

Sections

  • Twins — names identical once case and the -/_ separators are folded, yet configured as separate entities (FRE-SAPCD-… vs FRE_SAPCD_…, a real phenomenon on this platform).
  • Orphans — objects nothing references: accounts without a subscription, hosts and logins no subscription or account uses, whitelist entries no account allows.

Rules

  • Twins fold each configured name list onto itself; orphans check the cross-reference pair caches.
  • Usually one twin is legacy — but a green pair where BOTH work is deliberate, so check the tint before cleaning up.
  • Rows are tinted by each entity’s standard result colour; names link to their detail pages where one exists.

Tips

  • Not in Flow Manager is the reverse direction — values in the logs missing from the configuration. Together they bracket the config drift: configured but pointless, and real but unconfigured.
