Entities coverage cells

What it shows

The items behind one cell of the Entities or Logical, Partners, Domains, Applications & BL pages (Analyses menu): exactly the configured names (or whitelisted IPs) that cell counts. The title repeats the cell: entity group, column, count.

Columns

  • Name — the configured name, linking its detail page when seen in the transfer logs; on Whitelist pages the allowed IP, with the account(s) whose AllowIP whitelist carries it.
  • Direction — Configured pages only: In (the partner connects into SecureTransport) or Out (SecureTransport connects out); on External Partners the pair connection/movement — who dials whom, then which way the file travels.
  • Last transfer, Result — the newest transfer’s timestamp and Error (red) / OK (green); blank on a Configured page = never seen. Not Seen pages show Seen instead; External Partners drops Last transfer (the tint tells the outcome).
  • Accounts / Endpoints — on External Partners, Internal Applications, Internal Domains: member accounts and, in the same order, each one’s endpoint (In: the login the partner uses; Out: the host SecureTransport delivers to); collapsed to a count, click to expand, matching line by line.

Rules

  • Row tint = the item’s current result (the Entities Status figures): light green last transfer OK, light orange never seen, light red last transfer Error.
  • In & Out table: each side counted whole; an item flowing both ways counts in both (its row reads In + Out), so In + Out can exceed Total. Direction as a partition: In only / Both / Out only, summing to Total.
  • External Partners: the Connection, Movement and Use case buttons each narrow to one value; they combine, All lifts that group’s filter.
  • Sort: Result pages newest first; Configured and Seen pages alphabetical; External Partners on the partner name throughout.
  • Rebuilt every publish from the Show Seen reports’ data; each list reconciles with its table number.
