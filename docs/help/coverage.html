Configured entities

What it shows

  • Five pages — Logical, Partners, Domains, Applications, BL — each listing every configured name of that entity with what it is built from.
  • The home page’s status table opens them from the Entity label of the Logical, Partners, Domains, Applications and BL rows.

Columns

  • Logical flow / Partner / Domain / Application / BL — the name, linking its detail page.
  • Direction — connection/movement: who dials whom, then which way its subscriptions move the Files (a relay counts as both).
  • Subscriptions, Accounts, Endpoints (inbound logins and outbound hosts), Whitelisted IPs — folded to a count; click to expand.
  • UC1–UC4 — how many of its subscriptions are that use case: the name prefix, else the use case derived from the configuration.

Rules

  • A logical flow is a FlowID family condensed to domain_application_partner; domain, application and partner are its three parts. Partners merge into one organisation by shared endpoints, whitelist IPs, whitelisted host addresses and aliases.
  • A BL is a subscription’s BL tag or BL number; its members are the subscriptions carrying it.
  • The Connection, Movement and Use case selectors each narrow to one value; they combine, All lifts one.
  • Row tint = the entity’s result colour (Generic help).
