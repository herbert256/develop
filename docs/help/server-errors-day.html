Errors

What it shows

  • The server log’s Error and Warning lines from three angles, one tab each. Every figure counts log lines, not Files; the transfer log records no reason, the server log carries the why.

Tabs

  • Log reasons — Error lines per reason bucket (connection, PESIT refusal codes, network, routing): Reason, Errors, Share, Example message (the first occurrence, truncated). Below it, Reasons over time: ISO week, Reason, Errors, newest week first.
  • Heatmap — Hour × Monday…Sunday, each cell the Error + Warning lines, tinted by quartile (darker = busier); Errors / Warnings / Total per hour, the Total row per weekday.
  • Top messages — the 50 most-repeated Warning/Error message shapes: Level, Count, First, Last, Message shape.

Rules

  • Each PESIT reason= code is its own bucket; an unrecognised family lands in Other, so a new problem surfaces instead of vanishing.
  • A message shape has numbers, IDs, IPs and quoted values normalised away and is cut at 160 characters, so stack-trace variants group. Info lines are left out.
  • The date filter re-sums Log reasons, the heatmap (re-tinted), the shape counts and Reasons over time (a week cut by the range shows the count of its days inside it).

Tips

  • Click a reason, week, hour or shape for its 10 most recent lines.
  • Levels per day and per component: Server top view. The same reasons per subscription: Per flow. The failed Files per reason: Error reasons.
