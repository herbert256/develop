Report finder

What it shows

The whole report catalog on one searchable page: every report, dashboard and tool, by title with its group (the group of the Reports menu) and its one-line description. Type in the box to narrow the list; click a title to open the report.

Rules

  • The query is matched against each report’s title, its description and introduction words, its keywords and its page file name (so went-kaput finds “Trouble after Success”).
  • A title match weighs more: title matches list first, then the reports matched through description, keywords or file name — each group in catalog order.
  • The search grammar is the site-wide one: ? matches one character, * any run of characters, and the whole-word operators or, and, not combine terms (failure and not heatmap).

Tips

  • Ctrl/Cmd+K opens the finder from any page.
  • This page finds reports. To find an entity (account, subscription, login, host, logical flow, partner, application, domain or IP) use the magnifier beside the Entities link at the left of the top bar.
