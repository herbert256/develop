Report finder

What it shows

  • The whole catalog on one searchable page: every report, both dashboards and the search pages (Search, All files search).

Columns

  • Report — the title, a link to the page.
  • Group — its group of the Reports menu.
  • Description — the report’s one-line description.

Rules

  • The box matches each row’s title, description, keywords and page file name (pirates finds One-legged). Title matches list first.
  • Search syntax as everywhere: ?, *, and / or / not (failure and not heatmap). A search with no match says so.

Tips

  • Ctrl+K / Cmd+K on any page opens the command palette: reports from this catalog plus entities by name.
  • To find an entity (subscription, account, login, host, logical flow, partner, application, domain, BL, IP, source or target path) use Search, the 🔍 beside Entities.
