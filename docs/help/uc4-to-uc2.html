File in - File out › UC4 to UC2

What it shows

Files a partner delivered on a UC4 subscription that the matching UC2 subscription then collected: the delivered file did not move on to the CFT quickly enough, so the partner’s own pickup took it.

Rules

  • A UC4 File and a UC2 File pair when they have the same file name, the same login, the same subscription name apart from the UC4 / UC2 prefix (UC4-X with UC2-X, case ignored), and the UC4 File started earlier.
  • Each UC2 File pairs with the newest such UC4 File. The use case comes from the subscription name prefix only.

Tables

  • Per subscription pair — per UC4 / UC2 subscription and login: how many Files, the fastest, median and slowest gap between delivery and collect, and the first and last collect. Whole-window figures: From/To does not narrow this table.
  • Files — every pair, newest collect first, 500 per page: the file name, login, both subscriptions and start times, the gap and both CoreIds. From/To narrows it by the UC4 date; the search box filters it.
