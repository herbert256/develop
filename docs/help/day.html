Activity over time

What it shows

Transfer activity at every resolution, one tab each — per ISO week, per hour of day (plus the hour × weekday grid) and per weekday. The per-day figures, volume included, are the Top view.

Tabs

  • Per week — one row per ISO week (Monday–Sunday) by start date; Days = calendar days with data, Avg/day divides by it. From/To hides out-of-range weeks.
  • Per hour — Delivered = the OK Files started in that hour; Volume = every File started in it; the bar shows load relative to the busiest hour.
  • Hour × weekday — each cell counts the Files starting in that hour on that weekday, tinted by quartile of the busiest cell: batch windows show as dark blocks. The date filter re-sums and re-tints.
  • Per weekday — one row per day of week; Files = delivered (OK) Files, Error % = failures over every File of that weekday.

Rules

  • On the Top view, (partial start) / (partial end) marks an edge day of the collection window whose first time is after 02:00 or last time before 22:00: the export did not cover the whole day, so do not compare it with a full one.
