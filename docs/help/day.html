Activity per Day

What it shows

The Activity over time report: transfer activity at every resolution, one tab each — per day, per ISO week, per hour of day (plus the hour × weekday grid) and per weekday. The same Files, Error/OK split and volume throughout.

Tabs

  • Per day — one row per calendar day: Files, Error/OK, volume, first and last time seen. The Top view shows the same table with each day’s active accounts, subscriptions, flows, hosts and logins.
  • Per week — one row per ISO week (Monday–Sunday) by start date; Days = calendar days with data, Avg/day divides by it. From/To hides out-of-range weeks.
  • Per hour — Files = delivered (OK) Files started in that hour; the bar shows load relative to the busiest hour.
  • Hour × weekday — each cell counts the Files starting in that hour on that weekday, tinted by quartile of the busiest cell: batch windows show as dark blocks. The date filter re-sums and re-tints.
  • Per weekday — one row per day of week; Files = delivered (OK) Files, Error % = failures over every File of that weekday.

Rules

  • Per day lists every day of the calendar span between the first and last record: no Files gives an explicit “0” row with - in First/Last Time, so a quiet day is distinct from a missing one.
  • (partial start) / (partial end) marks an edge day of the collection window whose first time is after 02:00 or last time before 22:00: the export did not cover the whole day, so do not compare it with a full one.
