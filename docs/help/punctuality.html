Punctuality

What it shows

Does the daily file arrive on time? One row per subscription active on 8+ days: its typical arrival slot, how regular it is, its late arrivals and missed days. Tightest flows first.

Columns

  • Typical slot — the median arrival time over the window; the day’s first File defines that day’s arrival.
  • Window / Class — the spread (one standard deviation): Clockwork ±15 minutes or tighter (cron-driven flows, many at ±0 min); Regular within an hour; Loose within three hours; Irregular wider — event-driven flows, where late and missed have no meaning (those columns show “-”).
  • Late — arrivals over an hour past the typical slot (Clockwork/Regular only).
  • Missed days — a weekday the flow served on 75%+ of its calendar occurrences that passed without any File (Clockwork/Regular only).

Rules

  • Per (subscription, day) the earliest File time is kept; the median of those minutes is the typical slot.
  • The missed-day model builds each flow’s weekday profile and walks the whole calendar window: a Tuesday flow that skips a Tuesday is flagged, never running on weekends is not.
  • Always the full period (the model needs the whole window), so there is no From/To filter.

Tips

  • Click a row with late/missed counts for the exact dates.
  • Cronjobs shows the configured schedules these observed slots should match.
  • Went quiet measures idle days per account against its own cadence; this page is time-of-day granularity per subscription. Activity over time shows when the platform is busy overall; this page shows whether each individual rhythm holds.
