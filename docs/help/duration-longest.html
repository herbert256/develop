Longest Files

What it shows

The 50 longest delivered Files by wall-clock duration — first record start to last record end, so the store-and-forward wait inside SecureTransport and any retry idle are included.

Columns

  • Duration — sorts by the exact milliseconds.
  • Start Time, CoreId, Size, File name.
  • Subscription — the destination, linked to its detail page.

Rules

  • Only Processed (OK) Files are listed: a Failed, Expired or still-Waiting File is not a completed transfer, and a failure’s run time is a timeout, not a duration. Error transfers are mostly instant 0-byte attempts, a hanging one is a timeout — neither is a delivery.
  • Read from the logical-transfer cache (one row per CoreId): the 50 largest durations among the Processed Files.

Tips

  • A Duration or Start Time cell opens the transfer’s record page: every record of that CoreId in chronological order, with direction, status, protocol, login, remote host and transfer id.
  • The CoreId cell opens the File’s own File page under files/ — the error-page layout: the facts table, every record and the server log of its connections.
