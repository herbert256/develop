Subscriptions in boxes

What it shows

Every subscription flagged by any problem report, one column per report, plus the plain status boxes. Sorted by name; the name links its detail page.

Columns

  • One-legged transfers — CoreIds with only ONE leg (incomplete crossing), no OK File after the last; a later OK delivery = recovered, not flagged though the report still lists the history.
  • From green to red — delivered OK Files before, latest File failed (regression).
  • Trouble after Success — last transfer succeeded, server log shows Errors/Warnings since.
  • Only red — every File ever produced is an Error; never worked.
  • Waiting — newest File staged for pickup, not collected yet.
  • Expired — newest File expired: the retention sweep deleted the staged copy before any pickup, a lost delivery.
  • No Dir — configured REMOTE directory missing: we reach the partner, the listing fails “No such file”, no transfer starts. Still-open cases only; a directory found again later is not flagged.
  • No Files — UC3 flow polling faultlessly, never found a file: every listing succeeds, remote directory always empty.
  • Failing polls — the UC3 poll itself errors server-side (UC status / UC3: “server - error”); nothing listed or collected.
  • Login errors (in) — a connected login failed the incoming SSH screening (disallowed, unknown key, key failures, locked), no OK File since.
  • Login errors (out) — we failed to authenticate at the remote host (password, key or certificate policy), no OK File since.
  • OK / Seen / Not seen / Error / Server log only — site-wide result colours and coverage flag, from the same sources as the Transfer / Entities views (their full lists), so figures cannot drift.
  • Seen is the TRANSFER-scope reading; a flow known only from the server log sits in Server log only, so Seen + Server log only + Not seen = the whole estate.

Rules

  • Login-error flags are unresolved-only: a later successful delivery clears them.
  • Top boxes filter: opens on OK; a box narrows to what it flags; Total shows all rows; emptied columns hide.
  • Orange boxes (attention, or not working yet) precede red (failing). Row tint = the subscription’s site-wide result colour.
  • A flagged cell names its box and links into the report, pre-filtered to the subscription where the page has a search box.
  • Assembled at publish time from the reports’ own data files, so it agrees with them.
  • Exception: One-legged is recomputed from the transfer cache (pirates’ one-leg condition) and kept only when no OK File follows the last one-legged transfer, at full timestamp precision.
  • A report with no data here contributes no rows (empty column).

Reading combinations

  • Only red + Trouble after Success: never worked, still logging errors — hottest candidates.
  • From green to red alone: fresh regression, something changed recently.
  • One-legged alone: often attribution or protocol quirks, not a hard failure — check that report’s explanation.
