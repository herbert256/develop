Subscriptions in boxes

What it shows

  • Every configured subscription, sorted by name and tinted with its result colour; one column per box. One in several boxes is the first to open.
  • Opens on OK; a box narrows the table, Total subscriptions shows all. Empty columns hide; a flagged cell links its report.

Columns

  • OK / Error — the green / red result. Seen / Not seen — at least one File, or none.
  • Trouble after success — still green, but an Error was logged after its last OK transfer.
  • Waiting / Expired — its newest File is still staged, or the retention sweep deleted it unpicked.
  • No Files — a UC3 polling an always empty directory. No Dir — the listing answers No such file.
  • Missing cron — no cron expression: it never polls.
  • Went quiet — carried Files, then nothing for 7 days.
  • One-legged — a single-leg transfer.
  • From green to red / Only red — red after an earlier OK day, or never one OK File (Failed Subscriptions, Last green day).
  • Connection failures — a logged failed connection to the partner.
  • Deploy — ARSP0001 stopped the route, or a PeSIT profile lacks “Receive File As”; an account-named line counts for its subscriptions.
  • Login errors (in) / (out) — a connected login failed SSH screening, or we failed to authenticate at the remote host.

Rules

  • One-legged, Connection failures, Deploy and Login errors stay only while unresolved: an OK File after the last occurrence clears them (Login errors (in): a later day’s).
  • Boxes read the reports’ own data; a source absent here leaves its column empty.
