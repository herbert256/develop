Server Top View

What it shows

The server area’s landing page: one row per calendar day of the server log (data/server/cache/_parse.tsv, not the transfer log). Every figure is a plain count of log records, not Files.

Columns

  • Records — the day’s total, with a load bar.
  • Info / Warnings (amber) / Errors (red) / Error % — the level split; Error % = Errors ÷ Records.
  • TM (transaction manager) / PESITD / SSHD — records per component.
  • First / Last — the day’s first and last record time.

Rules

  • One pass buckets every record by date, level (I/W/E) and component letter; calendar gaps get explicit zero rows.
  • Records and the level and component columns are additive — a narrowed range re-totals them.
  • Always opens at the full date range, whatever range another page remembered; the total row is pinned to the top.

Tips

  • Click a day with at least one Warning or Error for its 10 most recent Warning/Error lines, newest first, inline; days with none are not clickable.
  • To see what caused a spike, open Errors or Top Messages (tabs above) and narrow their From/To to that day — this page cannot hold a range.
