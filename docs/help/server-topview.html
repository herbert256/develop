Server Top View

What this shows

This is the server area's landing dashboard, built from the platform's own log messages (data/server/cache/_parse.tsv) rather than the transfer log — a completely different data source from the Transfer reports. Every figure is a plain count of log records for that day, not Files.

One row per calendar day: total records, a load bar, the Info/Warning/Error split with the error rate, how busy each component was (TM transaction manager, PESITD, SSHD), and the first/last record time. The Warnings column is tinted amber; Errors are tinted red. This report always loads at the full date range regardless of any range remembered from another page, and the total row is pinned to the top of the table rather than the bottom.

How it's computed

One pass over the server parse cache buckets every record by its date, level (I/W/E) and component letter. Calendar gaps are filled with explicit zero rows. Error % is that day's Errors ÷ Records. Records and the level/component columns are additive, so narrowing the date range re-totals them.

Click to expand

Click a day with at least one Warning or Error to expand its 10 most recent Warning/Error lines (newest first) inline below the row. Days with none are not clickable.
