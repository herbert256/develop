Expired

What it shows

Staged UC2 files the nightly File Maintenance retention sweep (03:00, ~11 days after staging) deleted before any pickup — outcome Expired: never delivered, no longer collectable. Headline: the Expired Files, their share of every staged file whose fate is decided, and the volume that never reached a partner.

Sections

  • How long until expiry — calendar days from staging start to deletion. One global retention (~11 days): staged before 03:00 expires on day 11, later on day 10–11. No account deviates, so retention is not configured per partner.
  • Accounts — who the expired files were staged for, with the pickup rate = Collected / (Collected + Expired). Red = never collected a single file (a dead pickup flow: everything staged expires); orange = collects some, lets the rest expire.
  • Waiting there = staged within the last ~11 days, still collectable.
  • Expiries per sweep night — one row per 03:00 run and what it removed unclaimed; a missing night deleted nothing. The Accounts column is per night, not additive, so the Total leaves it blank.
  • Staged weekday — the weekday the file was staged, not deleted. One account can dominate this split: check the per-account table before reading a weekday pattern as partner behaviour.

Rules

  • Source: the transfer parse cache _files.tsv, outcome Expired, with the col-22 deletion timestamp set by bin/expire-files.sh from the server log’s File Maintenance … finished. Deleted files […] lines — the deletion leaves no transfer-log record.
  • Join: same account and file basename, deletion dated after staging.
  • Collected = staged files with a pickup (col 21). The sweep also removes already-collected staged copies — routine cleanup, not counted.
  • Expired counts as Error on every report, Waiting as OK; this page and Waiting Files show the two states separately.

Tips

  • Waiting Files (same group) shows both states per subscription and the individual files; this page aggregates the expired population. The Partner league gives each partner’s overall health verdict.
