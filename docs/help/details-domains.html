Domain Details

What it shows

The detail page of one business domain — the FIRST part of the three-part logical flow name domain-application-partner. The identity is name-derived: the same grouping as the Domains row on the Logical, Partners, Domains & Applications page.

Sections

  • KPI line — rank and share of traffic among all domains, failure rate, total volume, cadence, processed-transfer performance and a session count where durations are recorded.
  • Last error(s) — directly above Features, only when a subscription it moves files with has an error: one row per such subscription, its most recent error, newest first, with date and time, subscription and file. Red = failed file, orange = expired before the partner collected it.
  • Features — a Partner, Application, Domain or Logical breakdown holding exactly one row is folded away into a Features row, keeping its link and colour. The first Features row is the Domain itself.
  • Activity per day / week / hour / weekday — the day table leads with the Files count.
  • Breakdowns — every dimension its transfers touch: account, subscription, login, remote host, protocol, AV scan, security parameters, direction, action-by, mode. Subscription comes first below Activity; Account sits right under the Incoming/Outgoing connections tables.
  • 10 largest transfers.

Rules

  • The Subscriptions table’s nonzero Error count opens Failed files for that subscription at the full date range: every failed File of the subscription, so a page that sees only part of its traffic can list more.
  • Every count is in Files: one per logical transfer, split by its delivered (final-row) outcome, volume counted once per file.
  • The entity tables are cross-referenced with the FlowManager configuration: every name configured for this domain is listed, seen or not — green rows have logged data, red rows are configured but never seen; each links its own detail page.
  • Every configured domain has a page, seen or not. Background: light brown = seen & in, light blue = seen & out, light gray = seen & both/unknown, light yellow = never seen & in, light orange = never seen & out, light purple = never seen & both/unknown.
  • Configured both ways: every outcome splits into In - Error / In - OK / Out - Error / Out - OK by each file’s own direction; a file without a direction counts in Files and Volume only.

Tips

  • Click anywhere on a Last error(s) row (the subscription name included) for that file’s error page: every transfer leg and the server log of the failure.
  • Those are the files of the Failed Subscriptions list, which guarantees every subscription’s last error has a page.
