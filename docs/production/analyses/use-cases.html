The configured subscriptions grouped by their UC<n> prefix — the status columns of the Flow manager Entities table. Direction is the pair the detail-page titles use, connection side/file movement: who dials whom, then which way the file travels — so out/in means we connect out to the partner and the file comes towards us. Seen = Transfer + Server; Transfer = seen in the transfer logs (its subscriptions end the period Error or Ok by their last transfer); Server = surfaced only by the Server→Transfer step; Warning = configured but never seen — Total = Server + Error + Warning + Ok. Every nonzero count links the list of subscriptions it counts. Every use case with a published FlowManager template is listed — one with no subscriptions yet shows blank counts. What each UC means — who connects, which way the file travels, what triggers it — is on the Use Case definitions tab.
