For entity types other than subscriptions the result rolls up from the connected subscriptions. An UNTINTED row was logged but is not configured in FlowManager — it has no result to color by.

Counts Files — one logical transfer each; the bl is the subscription's BL tag from subscriptions.json (data/flow-manager/base/_bl.tsv). Names link to the logical / partner / application / domain detail pages. Volume is the file counted once; First/Last seen stay full-period under the date filter. The Total row counts each File once (the site-wide distinct figure); a narrowed date range re-totals over the per-bl rows, whose union attribution can claim one File for several bls — so a filtered Total can run slightly higher than the distinct figure it replaces, and snaps back to it at the full range.
