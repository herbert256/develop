Counts Files — one logical transfer each; the partner is the file's partner organisation (part 3 of its logical flow name, merged into organisations — data/flow-manager/base/_partners.tsv). Names link to the logical / partner / application / domain detail pages. Volume is the file counted once; First/Last seen stay full-period under the date filter. The Total row counts each File once (the site-wide distinct figure); a narrowed date range re-totals over the per-partner rows, whose union attribution can claim one File for several partners — so a filtered Total can run slightly higher than the distinct figure it replaces, and snaps back to it at the full range.
