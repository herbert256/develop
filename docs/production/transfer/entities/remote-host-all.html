Counts Files — one logical transfer each. A transfer is counted once per distinct remote host it involves (the Inbound source host and the Outbound destination host differ), so the per-host counts can sum to more than the number of distinct transfers. Error/OK is the transfer's delivered outcome; volume is the file counted once. Click an Error or OK count for that outcome's 10 most recent Files (newest first, by start time).
