Counts Files — one logical transfer each; the logical is the file's logical flow group (its FlowID condensed to a 3-part group name — data/flow-manager/base/_logicals.tsv). Names link to the logical / partner / application / domain detail pages. Volume is the file counted once; First/Last seen stay full-period under the date filter. The Total row counts each File once (the site-wide distinct figure); a narrowed date range re-totals over the per-logical rows, whose union attribution can claim one File for several logicals — so a filtered Total can run slightly higher than the distinct figure it replaces, and snaps back to it at the full range.
