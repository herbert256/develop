Configured in FlowManager but never seen in the transfer log in this window — including the entities that DID appear in the server log (the +Server scope counts those as seen and lists them under Seen). Every name links to its detail page, which lists the configured cross-references.

Counts Files — one logical transfer each; the application is part 2 of the file's logical flow name (data/flow-manager/base/_apps.tsv). Names link to the logical / partner / application / domain detail pages. Volume is the file counted once; First/Last seen stay full-period under the date filter. The Total row counts each File once (the site-wide distinct figure); a narrowed date range re-totals over the per-application rows, whose union attribution can claim one File for several applications — so a filtered Total can run slightly higher than the distinct figure it replaces, and snaps back to it at the full range. Click an Error or OK count for that outcome's 10 most recent Files (newest first).
