Counts Files — one logical transfer each. A transfer is counted once per distinct login it involves (its Inbound and Outbound rows may log different logins), so the per-login counts can sum to more than the number of distinct transfers. Error/OK is the transfer's delivered outcome; volume is the file counted once. Click an Error or OK count for that outcome's 10 most recent Files (newest first, by start time).
