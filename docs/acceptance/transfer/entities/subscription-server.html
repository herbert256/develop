These entities appear in the server logs (runtime Transfer Manager messages) but never in the transfer logs — the Server → Transfer step (bin/build/seen-in-server-log.sh) marked them blue (result=blue) so they surface here. They are what the +Server scope adds to Seen; under the Transfer scope they count as never seen. Each name links to its detail page.

Counts Files — one logical transfer each. A transfer is counted once per distinct subscription it involves (a transfer has a source and a destination subscription), so the per-subscription counts can sum to more than the number of distinct transfers. Error/OK is the transfer's delivered outcome; volume is the file counted once. Click an Error or OK count for that outcome's 10 most recent Files (newest first, by start time).
