# subscriptions.json tags[] entries starting with "BL" (2026-08-31, user
# request). Two whitespace-separated columns, # comments and blank lines
# ignored, shared by both environments:
#
#     <subscription name> <BL number>[,<BL number>...]

# case-insensitively, the configured spelling kept); a row naming an unknown
# subscription is reported and skipped.
